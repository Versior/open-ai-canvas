# 创作工作台续开发：模特、空间流程与智能体外观

## 本轮需求与验收边界

用户要求继续未完成开发，重点是“室内设计的功能展示用户感知不高，功能逻辑不够完善”“视频复刻界面单一普通，没有多功能”“解析接口太少了，去互联网论坛找多一些，各大平台的都要”。同时要求智能体对话皮肤与桌面形象资源协调，优化大小按钮，加入模特换装、多模特同款、一模多衣、姿势参考、模特换脸、智能换脸、智能换头、印花提取，并适配图片和视频。

这些功能复用既有生成任务、计费、资源归属和私有作品保存。每份方案须先保存再提交，已知任务只恢复监听，不确定提交保留幂等键。真实付费模型的换装、身份一致性、文字和动作质量需要独立验收；本轮不把通用图片编辑包装成已验证的专业换脸算法，也不声称整段视频能精确换脸。

## 已实现的功能

- 模特工作台提供八种模式。多模特同款每位模特独立配同一衣物；一模多衣固定人物、逐件配衣。其他模式每类选一张，不默默选取第一张。每类最多六张，保存素材与处理要求，逐张显示结果和任务状态。
- 换脸保留发型，换头包含发型与完整头部，姿势迁移保留目标身份和衣物。印花只提取已有图案，输出白底位图，不补造不可见区域。
- 生图台可把成品作为非真值参考。所有模式的图片均可继续生成展示视频；印花视频使用平面图案展示要求。图生视频单独计费，历史作品可恢复和下载，确定结束的图片任务可生成独立新版本。
- 视频首页增加六个实际入口：镜头拆解、脚本与导演、模特换装、人物与形象、印花素材、成片与交付。拆解入口在链接和文件模式均能定位输入；导演入口打开已完成拆解的方案。
- 室内页面展示效果图、三维空间、装修石材三类工作台，以及原图、方案、场景和材料的真实准备状态。三维页用紧凑入口保留预览空间。材料出图根据设计范围选择局部微调或整体改造；本轮材料开关明确控制报价、生成和轮次保存，不将材料要求粘入普通文案。
- 智能体提供随形象、云朵、手账、终端、星光、默认六种皮肤。在设置和右键菜单均可选择。自动皮肤复用图集采样提取代表色，忽略透明区、黑色轮廓和白色高光；审批和危险状态保留其颜色语义。大小控制改为五档文字和像素数。
- 形象导入支持文件夹和最多 300 个、合计 512 MiB 的队列，限流时保留待导入项，超限明确提示。准备脚本只校验并提取外层合集中的原始形象 ZIP，不上传、不上架，也不覆盖原包。

## 审查与交互回归

- 室内任务卡与材料出图共用可用任务判断，遵守后台的交互模式切换限制；禁用模式不进入生成表单。
- 模特图片与视频成品的所有非空资源标识先做格式校验，再做归属、类型与就绪检查，防止非法标识绕过资源引用收集。
- 对话跨设备回归使用真实查询容器，形象读取以隔离 API 返回空选择，避免真实网络请求影响会话、审批和账号隔离验证。
- 手机室内页修复整页滚动容器，确保下方工作台、材料和历史操作能到达。

## 后续开发方案与真实验收

1. 模特：用同一套授权人物与衣物分别评估八类操作，记录身份、版型、标识、印花、手部及遮挡错误；按通过率选择专用换装/姿势/身份模型，通过后端模型能力合同接入。精确视频换脸另需视频跟踪、遮挡和时间一致性算法，当前图生视频不能替代。
2. 室内：按业主、设计师、石材加工三种任务验收导航和生成结果。随后接入现场校准尺寸、多个实板与板号、开孔/边型、铺装损耗与加工厂规则；先区分设计概念、报价和可加工图纸的合同，再扩大范围。
3. 视频：每个平台至少准备一条授权短链、一条标准地址和一条失效地址；记录解析、媒体校验、限流及恢复结果。对供应商逐个启用，保留失败原因，建立真实覆盖矩阵。复刻成片继续核对身份跨镜稳定性、口播和字幕、镜头衔接。
4. 智能体：批量形象默认未上架，先核对动画行、视线、透明边界、代表色与深浅主题的可读性；大库按分类分批上架。继续验证低内存设备与长时间对话性能。

后续方案依赖真实样本、服务凭据或专业加工规则，不能以增加提示词或入口数量代替验收。
