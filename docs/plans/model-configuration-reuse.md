# 后台模型配置复用与识别

## 已实现

- 基本信息区提供跨系统渠道的完整配置复制。参数、素材传输方式、展示资料、定价、成本、Token 规则与参考视频计费进入同一份表单；保留目标身份与启停状态。独立上游 SKU 复制需明确勾选。
- 完整配置与价格复制共用来源选择组件，不再各自维护渠道读取、加载与错误状态。
- 文本预设选择后自动填写参数和空白标识，产品别名保留，空白上游 ID 使用预设实际 ID。
- 新增、编辑和复制草稿均可主动识别。识别使用相同型号配置、文本快照、明确的工作流及上游能力目录；不确定型号或协议时提示选择。价格与启停状态由管理员控制。
- 管理员资料接口仅在服务端使用已有凭据读取上游，不导入模型。保存复用既有创建/更新合同及后端校验，无数据库迁移。
- 桌面辅助区并排，窄屏纵向排列，使用现有主题变量与弹窗滚动。

## 验证

- 前端六个专项文件共 56 个测试通过；其中隔离 DOM 验证包含 11 条真实编辑器流程，覆盖完整复制、保存更新、标识保护、空白标识与别名填写、主动视频参数识别、价格保留及原有流程。
- 前端生产构建（含类型检查）、lint 和差异空白检查通过。
- 后端 app、handler 专项及 race 检查通过。覆盖管理员权限、未授权请求不访问上游、完整资料响应、不导入模型、上游失败及原有保存/目录预览。
- 真实后台使用独立数据库副本验证配置复制、保存、重开、参数识别、目录读取、空标识提示、390 像素宽度和明暗主题。没有触发收费模型生成；验证修改的副本模型已恢复。

## 交付边界

本轮实现保存在独立工作区，已合入远端主分支的能力/价格模板、协议建议及目录快照。完整复制与主动识别会保护明确选择的协议和参数，避免被未完成的自动建议请求覆盖；只读资料接口沿用渠道代理配置，原目录预览与快照流程保持独立。没有改写原开发目录的合并结果，没有部署服务器。

上游 `/models` 的能力字段取决于供应商。缺失字段继续显示为未知或沿用已选协议参数，不能称为已经自动确认全部供应商限制。生产渠道的实际可调用能力仍需结合供应商合同核对。
