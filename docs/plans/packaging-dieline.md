# 包装刀板：视频分析与实现范围

用户要求深度分析参考视频并开发类似功能，随后明确扩大为全方位开发，新增独立功能页面与对应后台管理。

## 参考证据

视频长 242.53 秒，720×960，展示 Illustrator 内的 MR.BOX PRO v1.0.29。已在本机提取时间采样、细节帧和 Vision OCR；原视频未公开上传。

可确认的流程：选盒型 → 输入尺寸、纸厚和结构细节 → 平面刀版 → 折叠与开盖 → 读取设计稿 → 面板贴图 → 相机、布局和主题。精品礼盒、袋体鼓胀、托盘、开窗和挂孔可见。工艺、识别和导出仅见按钮，未看到完整最终产物，不能据此断言其技术合同。

## 本轮合同

1. 浏览器用户页 `/packaging`，后台 `/admin/packaging`，登录后使用。
2. 十二参数结构：双插、反插、飞机盒、托盘、斜边展示、天地盖、抽屉、书型翻盖、对开盒、枕形、三边封袋与吸嘴袋；后台可新增参数变体、命名、分类和启停。
3. 刀版与三维共享面板、折边、孔洞和部件；切线布尔并集、出血偏移，独立部件在展开平面不相交。
4. 毫米外尺寸、纸厚、粘口/封边、插舌、间隙、展示前沿、开窗、鼓胀和吸嘴。非法开窗明确拒绝，不静默消失。
5. 硬盒实体厚度与父子铰链；独立盖底、内盒、套筒、书脊和翻门装配。软包装可控曲面预览。
6. 刀版、三维、并排；分栏、六面与等轴视角、旋转/平移/缩放、正交/透视、折叠播放、开合、全屏、灯光和背景。
7. 整版与面板图稿、位置/尺寸/旋转/透明度/适配；外印刷内纸色；黑白掩膜预览烫金、局部 UV 和压凸。
8. 服务端项目新建、读取、保存、另存、分页、删除、刷新恢复与离开保护；项目与目录 revision CAS，旧异步响应不能覆盖其他项目或账号。
9. 毫米 SVG/DXF、1K/2K/4K PNG、静态 GLB、硬盒折叠/开合动画 GLB、完整参数与原稿 ZIP；导入校验全部字段、面板、原稿类型及解压总量。
10. 后台真实统计、项目过滤、预览/导出、审计删除、盒型和材料 CRUD、启停、功能写入开关与配额。
11. 本人就绪图片校验；项目和资源关联事务保存；清理及资源物理删除检查包装引用。

## 能力与验证边界

生产纸厚补偿、压痕、套合和裱纸包边须实物白样核定；RGB 不代表 CMYK/专色印前。软袋曲面不模拟材料受力，不支持实体开窗或软体变形动画导出。压凸为浏览器/PNG 凹凸贴图，GLB 不承诺保留 bump 效果。

未实现 Illustrator 插件、AI 文件自动解析、自动识别和挂孔生产规则。这些需独立合同与真实样品，不能把视频按钮当成验证依据。

验证覆盖十二结构的折边端点、外尺寸、印刷朝向、部件排布、开窗与交付边界；真实 Gin/SQLite 覆盖权限、CAS、配额和资源引用。交付前运行类型检查、build、完整测试及隔离浏览器关键路径；生产白样与全设备性能留待实际验收。
