# 画布 AI 节点：竞品调研与实施方案

**状态：分项实施。** 竞品调研于 2026-11-25；各项的开发与实测状态见下表。未登录竞品生成作品、未调用付费模型，不把宣传案例当作效果、延迟或成本实测。

| 切片 | 实现 / 验证 | 尚未放行 |
| --- | --- | --- |
| 严格局改 | 图片节点区域编辑器默认严格模式；服务端冻结原图、校验二值蒙版、保护区四通道原样复制；落盘 PNG 的透明、半透明和不透明像素、首次执行与恢复后读取同一成品、跨账号拒绝均有回归。 | 实际渠道需逐个验证。未验收不能提交严格任务，用户可主动改为「参考重绘」。仅支持可在原像素坐标系对齐的静态图，不保证模型在框内的审美质量。 |

**开发合同：每个电商功能是可命名、连线、保存、重开的独立画布节点，不是跳转工具网站的快捷方式。** 共享节点底座不等于共用一份草稿。模型型节点复用原生的模型、张数、尺寸、画质等按能力显示的参数与费用确认；确定性本地工具不摆没有作用的模型选择器。创建、拖入、选材、配置、撤销均不发模型任务。

## 1. 产品结论

首期优先做四件事：**左侧节点栏 → 严格局部修改 → 一键详情页 → 透明 PNG 印花提取**。交互和成品约束由影策自己控制，模型只负责它擅长的图像生成或识别。换装、姿势、商品裂变可尽量复用已存在的工作台能力；不要为节点另造一套账户、模型设置、任务历史和计费。

目标用户是设计与电商运营。关键路径是「拖素材进画布 → 拖工具自动带入明确的输入 → 编辑/预览 → 确认生成 → 对比候选 → 复用或导出」。**创建节点不等于提交付费任务。** 原图不被覆盖，新结果可追溯、可撤销；不用接线也能从选中素材点击添加。

## 4. 能力矩阵

「可做」指技术上有明确实现路径；「需验证」指能开发流程但质量或接入条件不能预先承诺。此矩阵不是发布清单，实际覆盖以上方切片表为准。

| 节点与优先级 | 输入 → 交付 | 能做 / 不能承诺 |
| --- | --- | --- |
| **左侧节点栏 · P0** | 分类/搜索/最近使用 → 点击或拖入草稿，合法时连接选中素材。 | **可做。** 不承诺所有设备满帧，按第 5 节实测。 |
| **严格局部修改 · P0** | 原图 + 选区/保护区 + 描述或商品参考 → 原尺寸无损 PNG、对比、可撤销的新节点。 | **可做：** 编辑区以外的解码像素可严格锁定，适合改裤子颜色、纹理、去污点。**不承诺：** 选区内结果一定逼真；如果裙摆、影子必须超出选区，先预览并获得用户扩区确认。 |
| **一键详情页 · P0** | SKU 图片 + 已核实的属性/卖点 + 平台/模板 → 可逐屏编辑与单屏重试的草稿、长图及平台切片。 | **可做。** 卖点有来源或标待补，AI 猜的尺寸、材质、认证、价格不得直接出片。首期只接一个已确认的规格模板。 |
| **印花提取 · P0** | 服装/布料图 + 自选区域 → **透明 PNG**、棋盘格预览，可附可见区/补全提示。 | **平整、无遮挡可做；** 透视用校正，轻微折皱可近似。严重遮挡、反光、褶皱或重复花纹仅能推测，默认不补画；用户选择补绘时标为 AI 推断，不标为原厂原稿。 |
| **姿势裂变 · P1** | 同一模特与商品 + 姿势库/参考骨架 → 同一主体的静态姿势批次。 | **需验证。** 正侧背要测身份与服装一致性；原照片没有拍到的背面、手部细节不能保证准确。 |
| **一图多模 · P1** | 同一 SKU/服装图 + 多个已授权或合成模特 → 每个模特一组结果。 | **需验证。** 支持模特外观与风格切换；标识、图案、拼缝和面料逐张核对，不作为真实尺码或试穿结论。 |
| **商品裂变 · P1** | 商品锚点 + 场景/版式/渠道规格 → 一组商品图。 | **可做的默认模式：** 锁商品主体，仅改背景、阴影、文案和裁切。**需验证：** 新角度与新包装外观；缺少对应实拍时不宣称真实 SKU。 |
| **模特换装 · P1** | 人物图 + 上装/下装/整套 + 可选保护区 → 上身效果与原图对比。 | **需验证。** 人物脸和选区外可锁；下摆超界需确认扩区，花纹和层叠衣物可能失真。不能保证物理垂坠和合身度。 |
| **换脸 / 换头 · P2** | 授权来源图和目标图 → 显式标识的静态结果。 | **有条件可做。** 换脸约束到脸部；换头还包含发型/颈部边界，不混名。仅开放有同意记录的素材、合成模特或自有素材；不开放未授权冒用。多人、遮挡、视频身份连续性不得默认承诺。 |
| **动作裂变 · P2** | 静态档：动作参考或骨架序列 → 关键帧组；视频档：人物图 + 动作参考视频 → 短片候选。 | **静态可先做，连续视频需验证。** 短片先测动作对齐、关键帧身份、衣物飘动和闪烁；不承诺多人物、长段动作与复杂遮挡的稳定还原。 |
| **抠图、背景替换、批量规格 · P1** | 图片/商品组 + 蒙版、颜色、尺寸 → 透明素材与多规格交付。 | **可做。** 发丝、玻璃和细网需人工可改蒙版；表面低置信结果，不把不透明底图伪装成透明 PNG。 |
| **分层、矢量与设计交接 · P2** | 自有结构化画布或位图 → 可编辑 SVG、PDF、透明 PNG、素材/字体清单；位图另提供描摹候选。 | **可做：** 从现有文本、路径和图层生成交接包；用 SVG/PDF 导入 AI 或 CDR 后另存。**不能做：** 从任意位图无损恢复原生 `.ai/.cdr` 的图层、字体、曲线、隐藏对象。若将来采购官方支持的导出方案，需实测回读可编辑性，不能靠改后缀。 |

## 5. 左侧节点栏：交互和验收

- 左侧窄栏常驻，分「基础、图片精修、电商、模特、交付」；默认轻量预览，点击固定展开，六到八个常用项优先，其余由搜索查找。只读和无权限状态可见原因，不能插入；不在栏里渲染大图或触发模型请求。
- 细指针悬停建议 **120–160 ms** 淡入与位移，跨菜单的短延迟防止误合拢；焦点可见、相关 tooltip 不遮挡落点。触控用点击添加、显式拖柄或底部选择面板，不依赖 hover。拖拽有同类型单指针点击替代，参考 [WCAG 2.2 Dragging Movements](https://www.w3.org/TR/WCAG22/#dragging-movements)。
- 状态：`待选 → 拖动 → 合法吸附/不可放置 → 释放或取消`。轻量预览跟手，合法落点才显示吸附与连线预览；预览与正式节点用同一屏幕到画布坐标换算。放置只提交一次节点及可选连线的撤销事务。`Esc`、失焦、`pointercancel` 和画布外放手清理预览，不留半成品。松手可有约 **140–180 ms** 的落位过渡，但不延迟真实插入；`prefers-reduced-motion` 下关闭位移与弹跳。
- 复用现有设计 token、焦点和视口逻辑。拖动预览用 `transform`/`opacity` 与逐帧更新，不在每个 `pointermove` 写项目状态。验收有明暗、键盘/触屏、缩放、滚动、只读和重进恢复；普通桌面与限速/低配分开测，用现有 1,000 节点/连线基准比较回归。拟定桌面门槛：拖动帧间隔 P95 ≤ 20 ms、松手至节点可见 P95 ≤ 100 ms；低配实测后单列门槛，不能把桌面指标外推。

## 6. 局部修改：把像素保真做成成品合同

1. **冻结原图与坐标。** 解码后统一 EXIF 方向、像素网格和颜色处理；保存原图资产版本、尺寸、选区和保护区。框选、画笔及对象分割可以混用，分割只负责给建议，用户能修蒙版。严格模式必须有非空、非全图的有效编辑区；脸、上身和动作相关区域可作为显式保护区，保护优先。换裤子不改动作时不要邀请模型重做身体姿态。
2. **统一内部蒙版，向供应商适配。** 原图坐标、同尺寸单通道 PNG，白色可改、黑色保留；保护区从编辑区扣除。当前工具导出的「透明可改」是既有传输格式，转换只做一次，由适配器负责 alpha、黑白极性、输入先后和尺寸限制。严格模式只允许经过实测的蒙版渠道；无能力时关掉严格生成，用户可显式另选「参考图重绘」，不能静默降级。裁切模式带必要上下文，并保存确定的裁切/填充/缩放及其逆变换；不靠目测给结果拉伸对齐。
3. **模型只生成候选，影策决定哪些像素可用。** 发整图和蒙版是允许的；候选即使改了整图，也不能直接成为成品。校验返回大小、方向、裁切映射与对齐；对不可信的映射报失败并保留原图。按逆变换回填，仅在有效编辑区混合；羽化朝选区内，不能把脸或背景修改带出去。核心规则：允许区外直接拷贝原图像素，而不是对整张原图重采样。生成过程中的原始候选不得用作成品缩略图、分享预览或下载。
4. **发布前重新解码核验。** 成品为与原图像素尺寸一致的无损 PNG，按冻结的标准化像素基准逐通道比对编辑区外以及保护区，变化像素数必须为 **0**，包括 alpha。文件元数据和压缩字节不需要与原图一致。边缘缝隙、裤子纹理、轮廓、落影按区内质量另审；某些动作视觉线索在选区内，若要锁定，须缩小蒙版或增加保护，不把「选区外不变」夸大为「区内几何也永不变」。
5. **按任务而非页面保真。** 服务端只在合成、校验和资产写入成功后标成功。刷新、断线、Worker 重启、分享与下载都读同一成品；没有合成成品就明确失败/可恢复，不降级返回模型原图。界面显示选区叠加、原图/成品滑块、局部放大和失败原因。

## 7. 产物、成本与期数

- **PNG 印花：** 平面校正/分割/抠图优先，不必每张都跑扩散；机器验证 PNG 文件签名、可解码、像素尺寸与预期一致，交付确实含 alpha，边缘和背景存在实际透明像素。无法可靠分离则交给用户修选区或明示失败；输出色彩/像素尺寸，不用修改 DPI 标记冒充新增细节。
- **详情页：** 一键先生成结构草稿，出图与排版分离。SKU、标题、卖点、证据和平台约束可审；撤销、改文案、重排不重新付费生成。输出每屏与长图/切片，规范化切片预览，检查顺序、长度、OCR 和商品一致性。
- **异步与费用：** 入队快照固定素材版本、蒙版、模型/协议、参数与报价；提交前展示候选数量和总费用上界。相同业务提交去重，已取得供应商任务 ID 的不确定状态先恢复查询；只有确认旧任务终止或用户明确另开版本才重发。批次可限并发、逐项取消/重试，保留已完成项目。不得只比较单次模型价格，记录每张合格成品成本、P50/P95 延迟和每 100 次重试数量。上线前核对实际渠道价、账号权限、素材出境/保留条款及模型许可。
- **隐私与回退：** 图片、蒙版和姿态引用沿用资源归属校验；授权换脸素材默认不做公开素材库或默认外发，移除同意后不再用于新任务。按单节点/渠道灰度，关开关后不再接新任务，已存资产和未完成任务仍可按原合同查看与恢复。

首轮建议准备 30 张授权样本覆盖裤装、花纹、皮肤发丝、透明物、转身、遮挡和大图，再用简单几何、旋转原图、不同比例、半透明边缘做确定性回归。至少注入超时、产物尺寸错、无蒙版渠道、错版本、重复点击和重启；两位评审分别记录主体/品牌/姿态偏差和可交付性。能力上线门槛拟为 **UI/保护像素/文件树等硬约束 100%**，首版模型候选以 **盲审可交付率 ≥ 80%** 作为试点目标，公布样本量、拒绝率和成本；达不到只标实验，不用挑出的成功图代替整批成绩。
