# 包装刀板

用户入口 `/packaging`，管理入口 `/admin/packaging`，均需要登录。十二种结构包括双插、反插、飞机盒、托盘、展示盒、天地盖、抽屉、书型翻盖、对开盒、枕形、三边封袋与吸嘴袋。后台新增盒型复用这些结构的参数，不执行上传代码。

## 设计与交付

毫米外尺寸、纸厚和结构参数同时生成刀版与模型。刀版包含切线、折线、出血、面名与尺寸，实际轮廓进行布尔合并和出血偏移。硬盒使用实体纸厚和父子铰链；开窗放不入实际正面时明确报错。

插舌、防尘翼与粘耳按纸厚进入内层，折叠轨道同步这些层的位置；刀版的折边仍保持连接。飞机盒外高计入上下纸厚，盖底与抽屉间隙从实体纸面测量。

支持整版/面板图稿、拖动、旋转、尺寸、透明度、适配和移除；外面印刷、里面纸色。黑白掩膜白色生效，预览烫金、局部 UV 与压凸。最多 40 层，单图最多 25 MB / 4000 万像素，上传进入既有素材库。

刀版、三维、并排布局提供六面/等轴视角、正交/透视、旋转、平移、缩放、折叠播放、开合、全屏、背景与灯光。SVG/DXF 使用毫米，PNG 提供 1K/2K/4K，GLB 使用米；硬盒可导出折叠/开合动画，软包装导出当前曲面。

方案 ZIP 包含参数、原始图稿、带图稿 SVG 和 DXF。导入检查完整字段、有效面板、原稿类型和压缩/解压总量（100 MB）；缺原稿不会伪造完整导出成功。

## 设计历史、白样与用纸试算

撤销/重做最多保留 60 个不可变方案快照；同一字段的连续编辑在 400ms 内合并，图稿拖动结束后关闭合并组。`Ctrl/Cmd+Z` 和 `Ctrl/Cmd+Shift+Z` 支持快捷操作，输入框保留原生撤销。新建、加载、导入及账号切换清空历史。历史只恢复名称和方案内容，不回退项目 ID 或服务端 revision；回到最近保存的内容时显示已保存。历史本身不保存到服务器。

图稿默认保持当前宽高比例，支持等比放入、铺满、居中、90° 旋转、复制和置顶/置底。复制继续引用原始素材，不产生重复上传；保存仍校验资源归属和 40 层限制。

白样 PDF 使用 A4/A3，比较横竖版的页数，按 1:1 毫米输出切线/折线。边距 10–30mm，重叠 2–15mm，最多 200 页；包含行列编号、灰色裁边拼接线、共用坐标的十字标记与 50mm 校准尺。它只包含结构线，不包含图稿、工艺掩膜及双面套准。打印选择实际大小 / 100%，关闭自动适配。

纸张试算按含出血的整套刀版外框排列，独立扣除四边留白与上侧额外咬口，并比较 0°/90°；固定方向可表达丝向限制。净结构利用率使用实际面板面积，基础张数为需求份数除每张份数后向上取整，备用张数为基础张数乘输入百分比后向上取整。单张纸价不预填，未输入时不展示成本；成本只含纸材，试算单明确记录输入、方法与范围。

打印和用纸参数是当前弹窗的试算输入，关闭弹窗后重置；没有新增报价表、价格目录或 API，原项目/材料目录与权限合同保持不变。PDF 依赖为前端按需加载的 MIT `pdf-lib@1.17.1`。源码与官方竞品依据见仓库 `docs/plans/packaging-research.md`。

## 保存、权限与管理

项目真实保存到 `packaging_projects`；新建 expectedRevision=0，更新/删除提供当前 revision。冲突返回 409 / `packaging_project_conflict`。切换项目或账号后旧响应不能覆盖当前状态；刷新通过 `?project=` 恢复，未保存离开提示确认。

读取或导入期间产生的新编辑保留在当前稿；导入完成时提示重新导入，已上传的原稿保留在素材库。三维初始化失败时显示重启入口，刀版与项目保存仍可使用。

目录使用 `system_settings.packaging_catalog`，整体 CAS 冲突为 `packaging_catalog_conflict`。默认十二盒型、五材料、每用户 200 项目；后台配额 1–500。关闭写入或停用条目保留历史读取/导出，再次保存须选择启用条目。

图稿必须是本人的就绪图片。项目和 `packaging_project_resources` 关联同事务保存；素材删除、管理员删除和后台清理检查包装引用。删除项目解除引用并保留原稿。管理员读取其他用户图稿使用既有管理员文件接口，不扩张用户权限。

后台提供真实统计、分页过滤、项目预览/导出、按版本删除、盒型/材料维护与开放配额；目录保存和管理员删除记录审计。

审计写入与目录/删除处于同一事务，审计失败则业务回滚。PostgreSQL 多资源按 ID 排序锁定；资源删除提交后，等待该锁的项目保存重新检查图稿是否存在。

## 本地验证

包装专项 22 项、1152 次断言通过，覆盖十二结构、折边连接与轮廓、外尺寸、纸厚内层、48 组套合参数、开窗、曲面和方案导入。七种硬盒导出的 GLB 折叠/开合动画逐通道与实际场景矩阵一致。

真实 Chrome 路由检查通过：明暗主题、390 像素手机、十二盒型、SVG 栅格上传、服务器保存刷新、六种导出、1K/2K/4K PNG、ZIP 重新导入、导入期间新编辑、后台项目预览/删除、盒型/材料保存、目录 CAS，以及全部目录停用后的历史项目读取和导出。导出独立检查包含毫米 SVG/DXF、GLB 米单位与嵌入图稿、两段动画、PNG 尺寸/透明度及 ZIP 原稿完整性。

后端全量 `go test ./...` 通过；隔离 PostgreSQL 的并发配额、项目/目录 CAS、资源锁和完整 Schema 迁移通过。前端类型、lint 和构建通过；601 个测试文件隔离运行后，三个交互失败文件在单独重跑时通过，剩余两个翻译初始化失败在实施前基准上也可复现，全量测试并非全部通过。

生产试算优化新增 8 项专项，连同原包装专项共 30 项、2266 次断言通过。覆盖字段合并/分支/容量、毫米 PDF、横竖/重叠分页、十二结构含出血排布、数量/单价和等比适配。真实页面验证快捷键、保存检查点、v1→v2→v3 版本、图稿复制与层级、刷新恢复、PDF 与试算单下载、错误隔离，以及明暗主题和 390px 手机布局；PDF 另经 Poppler 独立解析和渲染。

隔离验收发现基线登录弹窗在路由外调用 `useSearchParams`，打开会白屏；本轮没有改动该模块，使用隔离测试账号的后端登录 API 建立验收会话。包装流程验证不等于该登录弹窗已修复。

## 生产边界

预览不等于印前认证；纸厚补偿、压痕、套合与裱纸包边须核对白样，RGB 未自动转换 CMYK/专色。软袋不模拟材料受力，不支持曲面实体开窗或软体动画导出。压凸为凹凸贴图，GLB 不承诺 bump 效果。未连接 Illustrator 插件、AI 文件解析和自动识别。

Schema 112 只新增两张包装表，SQLite 转 PostgreSQL 清单同步。迁移不改写旧项目；回滚须恢复同版本备份，旧二进制不能直接使用新账本。
