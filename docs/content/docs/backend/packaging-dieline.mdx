# 包装刀板

用户入口 `/packaging`，管理入口 `/admin/packaging`，均需要登录。十二种结构包括双插、反插、飞机盒、托盘、展示盒、天地盖、抽屉、书型翻盖、对开盒、枕形、三边封袋与吸嘴袋。后台新增盒型复用这些结构的参数，不执行上传代码。

## 设计与交付

毫米外尺寸、纸厚和结构参数同时生成刀版与模型。刀版包含切线、折线、出血、面名与尺寸，实际轮廓进行布尔合并和出血偏移。硬盒使用实体纸厚和父子铰链；开窗放不入实际正面时明确报错。

支持整版/面板图稿、拖动、旋转、尺寸、透明度、适配和移除；外面印刷、里面纸色。黑白掩膜白色生效，预览烫金、局部 UV 与压凸。最多 40 层，单图最多 25 MB / 4000 万像素，上传进入既有素材库。

刀版、三维、并排布局提供六面/等轴视角、正交/透视、旋转、平移、缩放、折叠播放、开合、全屏、背景与灯光。SVG/DXF 使用毫米，PNG 提供 1K/2K/4K，GLB 使用米；硬盒可导出折叠/开合动画，软包装导出当前曲面。

方案 ZIP 包含参数、原始图稿、带图稿 SVG 和 DXF。导入检查完整字段、有效面板、原稿类型和压缩/解压总量（100 MB）；缺原稿不会伪造完整导出成功。

## 保存、权限与管理

项目真实保存到 `packaging_projects`；新建 expectedRevision=0，更新/删除提供当前 revision。冲突返回 409 / `packaging_project_conflict`。切换项目或账号后旧响应不能覆盖当前状态；刷新通过 `?project=` 恢复，未保存离开提示确认。

目录使用 `system_settings.packaging_catalog`，整体 CAS 冲突为 `packaging_catalog_conflict`。默认十二盒型、五材料、每用户 200 项目；后台配额 1–500。关闭写入或停用条目保留历史读取/导出，再次保存须选择启用条目。

图稿必须是本人的就绪图片。项目和 `packaging_project_resources` 关联同事务保存；素材删除、管理员删除和后台清理检查包装引用。删除项目解除引用并保留原稿。管理员读取其他用户图稿使用既有管理员文件接口，不扩张用户权限。

后台提供真实统计、分页过滤、项目预览/导出、按版本删除、盒型/材料维护与开放配额；目录保存和管理员删除记录审计。

## 生产边界

预览不等于印前认证；纸厚补偿、压痕、套合与裱纸包边须核对白样，RGB 未自动转换 CMYK/专色。软袋不模拟材料受力，不支持曲面实体开窗或软体动画导出。压凸为凹凸贴图，GLB 不承诺 bump 效果。未连接 Illustrator 插件、AI 文件解析和自动识别。

Schema 112 只新增两张包装表，SQLite 转 PostgreSQL 清单同步。迁移不改写旧项目；回滚须恢复同版本备份，旧二进制不能直接使用新账本。
