# 包装刀板

用户入口 `/packaging` 向游客展示完整工作区和原生设计示例，真实图层编辑、上传、保存、导出与模型生成要求登录；管理入口 `/admin/packaging` 要求管理员。十二种结构包括双插、反插、飞机盒、托盘、展示盒、天地盖、抽屉、书型翻盖、对开盒、枕形、三边封袋与吸嘴袋。后台新增盒型复用这些结构的参数，不执行上传代码。

页面分为结构、设计、3D 与工艺、交付四个工作区。结构页集中尺寸与材料；设计页使用图层列表、真实刀版和独立属性栏；3D 页集中表面与工艺；交付页集中检查、彩稿、分版和方案包。默认显示完整 3D 示例，游客可切换视角和工艺检查，不创建服务端项目或付费任务。贴图、影棚、PDF 与 GLB 在浏览器计算；公开目录仍有普通 HTTP 请求，静止 3D 按需渲染。

## 设计与交付

毫米外尺寸、纸厚和结构参数同时生成刀版与模型。刀版包含切线、折线、出血、面名与尺寸，实际轮廓进行布尔合并和出血偏移。硬盒使用实体纸厚和父子铰链；开窗放不入实际正面时明确报错。

插舌、防尘翼与粘耳按纸厚进入内层，折叠轨道同步这些层的位置；刀版的折边仍保持连接。飞机盒外高计入上下纸厚，盖底与抽屉间隙从实体纸面测量。

支持原生文字、矩形、椭圆与整版/面板图片。文字可编辑字体类别、毫米字号、字重、对齐与颜色；图层可设置用途、显示、锁定、面板、毫米变换、等比适配、复制和顺序。同一盒型修改尺寸时保留图层在面板中的相对中心与宽高比例；整版图层保留原坐标。最多 40 层，单图最多 25 MB / 4000 万像素，图片上传进入既有素材库。

文字支持独立字号、1–3 倍行距、0–20mm 字距与自动换行。中文按字符、英文优先按单词折行，超长单词继续折行；显式换行和空行保留。文本框缩放保持字号，可按实际文字展开高度或缩小字号适配。刀版 SVG、三维贴图和 PDF 共用排版计算；SVG 保留行内空格，字体使用当前系统字体。字号、行距、字距和换行字段随现有方案 JSON 保存及重导入。

刀版可放大当前面并显示距切边、折边与开窗 3mm 的文字安全区。九宫格按旋转后的图层外框对齐并预留 3mm；异形边与孔洞继续核对安全区。跨面复制保留原图层，在目标面保持相对中心并等比缩放尺寸、字号和字距；工艺、旋转和内容保留。手机画布保留编辑高度，属性栏支持独立滚动。

八种用途为四色印刷、烫金、烫银、局部 UV、局部亮面、击凸、击凹、镭射。图片工艺按 sRGB 亮度生成掩膜，白色生效、黑色无作用；原生文字与图形按自身轮廓生成。工艺图层不进入四色彩稿；需要同一元素同时印刷与做工艺时复制一层并指定不同用途。

平滑白卡、牛皮纤维、细纹纸纹与无膜、哑膜、亮膜、触感膜可组合。四种影棚使用本地生成的反射环境，不下载远程 HDRI。独立工艺通道和 20mm UV 棋盘用于检查位置；凸凹深度为高度/法线视觉预览，镭射采用随视角变化的材质。影棚或深度调整不重复烘焙彩稿贴图，预览与 PNG/视频共用外观设置。

刀版、三维、并排布局提供六面/等轴视角、正交/透视、旋转、平移、缩放、折叠播放、开合、全屏、背景与灯光。SVG/DXF 使用毫米，PNG 提供 1K/2K/4K，GLB 使用米；硬盒可导出折叠/开合动画，软包装导出当前曲面。

方案 ZIP 包含参数、原生图层、表面设置、引用原始图片、带图稿 SVG、DXF 和 preflight.json；有使用工艺时另附对应 `process-<role>.svg`。工艺 SVG 画幅与刀版完全一致，白色生效、黑色无作用，无切折线；预览与导出统一 sRGB 亮度。彩稿可延伸至真实外轮廓出血区，面板扩展不进入相邻面板内部；系统不会自动生成边缘内容，仍需检查实际出血覆盖。

交付页独立下载 1:1 彩稿 PDF，原生文字、图形和图片按 300 DPI 无损合成，切线/折线保持矢量，并使用 CutContour / Crease Separation 专色叠印。PDF 带 TrimBox、BleedBox、关闭打印缩放的声明和版外参考标记。RGB 用于评审；CMYK 使用公式转换，没有 ICC 输出配置或 PDF/X 认证。所有工艺 PDF 打成独立 ZIP，使用相同尺寸/坐标、黑色覆盖区和灰度强度，不混入刀线。每版上限 4000 万像素，超限明确要求拆分，不静默降低 DPI；完整方案 ZIP 不包含这些独立 PDF。

交付检查对图片用实际像素和毫米尺寸计算较低轴 DPI，原生文字/图形明确显示原生图层；所有图层检查旋转后与实际轮廓/孔洞的交集。低于 300 DPI 是提示，缺图或缺面板则阻断完整方案交付。隐藏图层不进入视觉/分版，仍保留在可编辑方案及图片资源引用中。导入检查完整字段、有效面板、原稿类型和压缩/解压总量（100 MB）；缺原稿不会伪造完整导出成功。

真实浏览器使用 Canvas 字形宽度与末行下伸尺寸检查文字溢出，超出文本框阻断带图稿 SVG、彩稿/工艺 PDF 和方案包；点击问题可定位图层。空文字、文本框越过 3mm 安全区是警告，隐藏或透明文字不阻断。安全区检查对象是文本框，不宣称精确字形与工厂最小留边验收；未提供字体测量的程序化报告明确标记未测量字形宽度。无图稿 DXF 与结构白样不受文字溢出影响。

「动画视频」录制 8 秒折叠后开合，十二结构都支持，最高 2K；浏览器支持时输出 MP4，否则 WebM。支持取消，退场/账号切换停止录制，视频透明背景转换为浅色背景。录制按实际性能产帧，不承诺固定 30fps；保存当前方案状态不受录制影响。「动画 GLB」含独立 fold/open 轨道，须三维软件选择轨道播放；软袋曲面形变使用视频，静态 GLB 保留当前姿态。取景覆盖整个运动边界，避免展开被裁掉。

## 设计历史、白样与用纸试算

撤销/重做最多保留 60 个不可变方案快照；同一字段的连续编辑在 400ms 内合并，图稿拖动结束后关闭合并组。`Ctrl/Cmd+Z` 和 `Ctrl/Cmd+Shift+Z` 支持快捷操作，输入框保留原生撤销。新建、加载、导入及账号切换清空历史。历史只恢复名称和方案内容，不回退项目 ID 或服务端 revision；回到最近保存的内容时显示已保存。历史本身不保存到服务器。

图稿默认保持当前宽高比例，支持等比放入、铺满、居中、90° 旋转、复制和置顶/置底。复制继续引用原始素材，不产生重复上传；保存仍校验资源归属和 40 层限制。

刀版直接操作提供八向手柄、固定对面锚点、角点等比/边点自由、旋转手柄、Shift 15°吸附及毫米/面板吸附。Alt 连续移动或自由缩放，方向键 1mm、Shift 10mm、Alt 0.1mm。拖动冻结画幅；Esc/pointer cancel 恢复原稿和历史分支，长时间停顿也保持一手势一步撤销。

白样 PDF 使用 A4/A3，比较横竖版的页数，按 1:1 毫米输出切线/折线。边距 10–30mm，重叠 2–15mm，最多 200 页；包含行列编号、灰色裁边拼接线、共用坐标的十字标记与 50mm 校准尺。它只包含结构线，不包含图稿、工艺掩膜及双面套准。打印选择实际大小 / 100%，关闭自动适配。

「纸张用量与拼版」提供外框网格和整套轮廓排料。四边留白、上侧额外咬口、出血间距进入计算；0°/90° 可混排，也可固定方向。点击开始后在浏览器 Worker 搜索 2/5/10 秒，显示当前最佳套数，可取消；几何参数变化或退场会终止搜索。搜索最多 500 套，结果至少保留完整网格基准，不保证最优。多部件保持整套相对位置，开窗和内部空洞不作嵌套空间。

对照表列出网格与轮廓结果、每张完整套数、净结构利用率和基础用纸。净利用率使用实际面板面积；基础张数为需求套数除每张套数后向上取整，备用张数为基础张数乘输入百分比后向上取整。价格不预填，未输入时不展示成本；只计算纸材，不代表印刷工艺报价。

可导出含全部套数的整纸 1:1 SVG、DXF、PDF 和带位置/方法的 JSON 试算单。导出前检查真实出血轮廓碰撞、间距、方向和纸张边界；几何精度 0.001mm，间距容差 0.002mm。切线、折线、出血保留独立组/层，参考纸张与可用区域使用 SVG/PDF 的 REFERENCE、DXF 的 DIMENSION，不可作为切线。上侧留白加咬口至少 9mm 时附 50mm 校准尺。预览最多显示前 200 套，导出包含全部；超过 2000 套明确拒绝。整纸仅输出结构，不含彩稿拼版、共刀、孔内嵌套或分部件拆排。

打印和用纸参数是当前弹窗的试算输入，白样/拼版切换保留参数及最佳结果，并停止正在运行的搜索；关闭弹窗后重置。没有新增报价表、价格目录或 API，原项目/材料目录与权限合同保持不变。PDF 依赖为前端按需加载的 MIT `pdf-lib@1.17.1`。源码与官方竞品依据见仓库 `docs/plans/packaging-research.md`。

## 模型效果图

保存方案后，选择 3D 视角并点击「用此视角生成效果图」。参考截图与项目 revision 绑定；有未保存编辑时先保存。效果图库始终使用服务端保存快照，生成要求也以服务端同版本尺寸/材料构建。

选择支持一张参考图的图片模型，填写场景和最多 1200 字补充要求。棚拍、主视觉、生活场景、工艺特写保留既有印刷；包装创意提案允许探索配色与排版。每次生成一张，使用真实模型参数与报价，不静默替换模型。结果和参考进入既有素材库，独立于刀版及印刷稿。

结果可下载或「继续修改」。继续修改使用原结果资源、关联父任务，服务端确认它属于同账号/项目/保存版本且父任务已成功；旧版本结果仍可查看下载，需要重新从当前方案生成后才能继续修改。后台只读图库使用管理员资源接口，不能代用户触发生成或取消。

提交复用 `POST /api/tasks`：type=canvas_image、mode=image、config.count=1；metadata 的 source=packaging-mockup，附 packagingProjectId、packagingRevision、packagingReferenceId、packagingScene 和可选 packagingParentTaskId。referenceImages 必须且只能有一张 resource 引用。包装归属/版本、就绪图片、生成开关先校验，后续继续执行通用模型能力、渠道、配额、账务和队列准入。包装 ID 不放进通用任务的 projectId。

图库读取 `GET /api/packaging/projects/:projectId/mockups` 和管理员对应路径，pageSize 1–30、前端每页 12 条；按所有者/任务类型/来源/项目过滤，返回安全摘要、参考与结果资源、revision 和父任务，禁止缓存。不返回供应商配置或原始 inputJson；要求摘要沿用通用任务的 500 字限制。活跃任务轮询，支持用户取消和结算信息。

后台目录 mockupEnabled 与 enabled 同时开启才可生成。默认目录开放生成；保存目录中显式 false 会关闭生成。关闭后历史仍可读取。通用图片工作台开关只控制独立工作台；包装生成由包装开关控制，并继续遵守模型权限与账务规则。上传成功后任务提交失败，参考图保留素材库并明确提示。

AI 不保证字形、品牌细节或结构准确，输出不自动成为生产稿。实际模型结果必须人工核对；浏览器白样、图稿检查和效果图分别承担各自用途。

## 保存、权限与管理

项目真实保存到 `packaging_projects`；新建 expectedRevision=0，更新/删除提供当前 revision。冲突返回 409 / `packaging_project_conflict`。切换项目或账号后旧响应不能覆盖当前状态；刷新通过 `?project=` 恢复，未保存离开提示确认。

读取或导入期间产生的新编辑保留在当前稿；导入完成时提示重新导入，已上传的原稿保留在素材库。三维初始化失败时显示重启入口，刀版与项目保存仍可使用。

目录使用 `system_settings.packaging_catalog`，整体 CAS 冲突为 `packaging_catalog_conflict`。默认十二盒型、五材料、每用户 200 项目；后台配额 1–500。关闭写入或停用条目保留历史读取/导出，再次保存须选择启用条目。

图片图层必须引用本人的就绪图片。原生图层使用空 `resourceId` 与 `content`，不进入资源引用表，也不触发图片读取/重上传；伪造带资源 ID 的原生图层会被拒绝。项目和真实图片的 `packaging_project_resources` 关联同事务保存；素材删除、管理员删除和后台清理检查包装引用。删除项目解除引用并保留原稿。管理员读取其他用户图稿使用既有管理员文件接口，不扩张用户权限。

文档仍为 `version: 1`。`content.kind=text` 保存 `value`（可为空）、`font=sans|serif|mono`、`weight=400|700`、`align=left|center|right` 与 HEX `color`；`content.kind=shape` 保存 `shape=rectangle|ellipse` 与 `color`。图层的 `visible`、`locked` 为可选布尔值；可选 `surface` 保存 `paper`、`film`、`studio`、`inspection`、`quality=1024|2048|4096`、`depth`、`foilColor` 和 `silverColor`。前后端入口校验保持一致。扩展只存入现有 document JSON，没有新增数据库表或 Schema 迁移。

后台提供真实统计、分页过滤、项目预览/导出、按版本删除、盒型/材料维护与开放配额；目录保存和管理员删除记录审计。

审计写入与目录/删除处于同一事务，审计失败则业务回滚。PostgreSQL 多资源按 ID 排序锁定；资源删除提交后，等待该锁的项目保存重新检查图稿是否存在。

## 本地验证

包装专项 22 项、1152 次断言通过，覆盖十二结构、折边连接与轮廓、外尺寸、纸厚内层、48 组套合参数、开窗、曲面和方案导入。七种硬盒导出的 GLB 折叠/开合动画逐通道与实际场景矩阵一致。

真实 Chrome 路由检查通过：明暗主题、390 像素手机、十二盒型、SVG 栅格上传、服务器保存刷新、六种导出、1K/2K/4K PNG、ZIP 重新导入、导入期间新编辑、后台项目预览/删除、盒型/材料保存、目录 CAS，以及全部目录停用后的历史项目读取和导出。导出独立检查包含毫米 SVG/DXF、GLB 米单位与嵌入图稿、两段动画、PNG 尺寸/透明度及 ZIP 原稿完整性。

后端全量 `go test ./...` 通过；隔离 PostgreSQL 的并发配额、项目/目录 CAS、资源锁和完整 Schema 迁移通过。前端类型、lint 和构建通过；601 个测试文件隔离运行后，三个交互失败文件在单独重跑时通过，剩余两个翻译初始化失败在实施前基准上也可复现，全量测试并非全部通过。

生产试算优化新增 8 项专项，连同原包装专项共 30 项、2266 次断言通过。覆盖字段合并/分支/容量、毫米 PDF、横竖/重叠分页、十二结构含出血排布、数量/单价和等比适配。真实页面验证快捷键、保存检查点、v1→v2→v3 版本、图稿复制与层级、刷新恢复、PDF 与试算单下载、错误隔离，以及明暗主题和 390px 手机布局；PDF 另经 Poppler 独立解析和渲染。

游客访问更新已修复登录弹窗的根路由上下文。原生图层升级已在真实路由通过游客添加拦截与表单登录，隔离测试账号保存/重载文字、烫银工艺和表面设置；当前验证记录与待人工核对项见[待测试](/docs/progress/pending-test)。

## 生产边界

预览不等于印前认证；纸厚补偿、压痕、套合与裱纸包边须核对白样。CMYK 公式转换不代替印厂 ICC/PDF/X、套准与工艺验收；SVG 原生文字依赖所选系统字体，PDF 彩稿文字栅格化。软袋不模拟材料受力，不支持曲面实体开窗或软体动画导出。凸凹为贴图预览，GLB 不承诺 bump 效果。未连接 Illustrator 插件、AI 文件解析和自动识别。

Schema 112 只新增两张包装表，SQLite 转 PostgreSQL 清单同步。迁移不改写旧项目；回滚须恢复同版本备份，旧二进制不能直接使用新账本。
