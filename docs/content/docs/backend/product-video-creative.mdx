# 视频创作与对比交付

视频首页提供「素材创作」「参考视频复刻」「人物与服装处理」三个入口。热点选题位于顶部，商品展示必须提交商品图；口播带货必须有出镜人物与声音。上传素材后的 AI 分析只回填未手动修改的字段，推断信息继续等待确认。首页保存作品后启动导演策划，生成、配音、字幕、剪辑与交付沿用既有工作台。

## 作品与任务

作品仍以 `version: 2` 保存于当前用户的 `EcommerceLibrary.payload.productVideos`。参考视频作品使用 `source`；无原片的新创作使用 `creative`，两者互斥，不制造原片占位素材。`creative` 保存用途、风格、目标时长、观众、热点、资料确认、素材观察、多份完整脚本、选用方案和导演任务。人物身份、姿势、场景与声音分别填写并绑定用途。

策划要求图文模型能接收所需参考图片。先保存操作编号与输入快照，再提交通用文本任务；未知提交结果沿原操作编号恢复，已经创建的任务按任务编号查询。素材、人物、声音或用途改变后，旧方案不可执行。结果回写再次核对账号、输入和当前任务，避免跨账号或旧请求覆盖。

服务端 `product_video_creative.go` 校验镜头连续时序、台词预算、事实依据、冻结配置，以及素材和任务的账号归属。写路径失败不会伪装成保存成功。视频生成与人物处理保留参考视频的精确选段、尺寸和画幅；候选时长不足时标明失败，避免以静止尾帧冒充完整视频。

## 热点账号

普通用户仅通过 `GET /api/video-creation/trends` 读取已经发布的标题、来源链接和抓取时间。未发布的站点账号返回空列表；更新失败保留旧内容并标记延迟。公开热搜使用固定来源和出站校验，不接受客户端提供任意抓取地址。

管理员在后台「视频创作 → 热点账号」完成连接、预览和发布。热点宝使用站点管理员提供的有效 Cookie 或服务器 `CANVAS_DOUHOT_COOKIE`，是服务端网页接口。巨量千川和巨量平台使用获批应用的官方 OAuth，管理员选账户后同步。打开第三方网页不会自动把登录状态传回本站；官方授权必须登记本站 HTTPS 回调。

`CANVAS_QIANCHUAN_APP_ID`、`CANVAS_QIANCHUAN_APP_SECRET`、`CANVAS_QIANCHUAN_AUTHORIZE_URL` 及对应 `CANVAS_OCEANENGINE_*` 只在服务器配置。账号凭据加密保存，前台不接收 Cookie、令牌或广告主信息。官方账户素材与广告项目推荐按实际来源展示，不标成全站热榜。真实账号和生产回调仍需管理员验收。

## 左右对比导出

在复刻交付中可把原片放左侧、复刻放右侧，合成为同一个 MP4。`timeline.comparison` 保存原片授权确认、声音选择和原片片段；每侧必须连续且等长。默认使用复刻声音，也可选择原片声音或静音。画幅为两侧合计尺寸，原比例以等比留边保留。

`render.sourcePieces` 冻结成片对应的原片选段，删除镜头时左侧同步跳过。`comparisonRender` 保存快照签名、任务编号、资源与错误；刷新查询同一任务，成片或声音变化后重新导出。现有 FFmpeg Worker 校验资源归属并探测实际时长，拒绝越界选段。对比合成不调用模型，不新增数据表。

## 验证边界

专项测试覆盖素材输入、必填人物和声音、旧方案失效、保存后提交、未知结果恢复、账号隔离、选段时长、对比映射、管理员发布与凭据保护。浏览器验收使用真实路由和同版本前后端。

自动化通过不代表通用视频模型已经达到数字人专用供应商的身份、口型或音色一致性。模型效果、真实热点账号授权及生产导出需要实际素材与账号验收。
