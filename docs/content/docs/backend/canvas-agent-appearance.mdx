# 画布 Agent 外观与形象

宠物待机首帧默认停留 8 秒，再播放一次轻动作；工作动作继续按原速度播放。默认不随全窗口鼠标移动切换视线，商店播放预览可启用视线跟随。悬停招手有 20 秒冷却，完成、失败、取消及拒绝仅播放一次状态动作后恢复待机。切换图集清除旧形象动作。尊重减少动效和页面隐藏状态。

创作对话的助手头像使用当前用户在服务端选定形象的待机静态缩略图；切换形象后同步更新，不在每条消息里播放整张图集。侧栏品牌入口只显示当前 Logo，顶部保留页面名称，避免长品牌副标题重复。宠物气泡在外层没有用户主题变量时，使用站点背景和前景变量，防止 SVG 黑底和深色文字叠在一起。

后台「系统设置 → 智能体样式 → GitHub 同步」连接 [独立形象素材仓库](https://github.com/Versior/agent-pet-library)，保存清单地址后由服务端下载。支持进度、停止、摘要校验和重复去重，不需要手动下载 ZIP 再上传。新形象仍默认未上架，批量设置后上架；已有配置和用户选择不被同步覆盖。

窗沿形象空闲时保留 48px 可见区域，露出眼睛，底部固定在输入框上沿；工作、审批、悬停和键盘聚焦时展开。图集按透明头顶计算偏移，绿幕视频按抠像后的实际内容顶边与 contain 留白计算，不再用固定比例猜头部位置。视频暂停时仍绘制可用首帧，暂停后不继续逐帧处理。切换形象包会重新测量边界。该行为替代早期 24px 只露额头的布局。

管理员在「站点及外观 → 画布配置」设置助手名称、入口文字、面板标题、欢迎标题、欢迎说明和输入提示。助手名称独立于站点品牌，例如站点为“影策”、助手为“小鱼”。文案中的 `{agentName}` 会替换为助手名称，并作为普通文本渲染。

助手名称同时用于界面文案和 AI 自我介绍。服务端在每个新回合从同一份外观配置读取名称，将其作为 JSON 名称数据加入内置身份规则；站点品牌、模型供应商、个人设定和历史回复中的旧名称不覆盖它，也不将名称解释为行为指令。

保存后当前页面立即更新，其他已打开页面在重新获得焦点、切回前台或刷新时读取最新配置；刷新失败保留已有名称。新对话和已有对话的后续回合使用新名称，正在执行的回合保留创建时的身份快照，历史消息不重写。其他文案字段仍只改变展示，技能和工具权限不变。运行中插话提示保留原有操作说明。入口文字和欢迎说明允许留空。

## 用户自选形象（宠物皮肤）

除了站点统一配置的形象，管理员可在「系统设置 → 智能体样式」开放一批形象给用户自选。形象使用 Codex 宠物图集：8 列，单格 192×208；v1 为 9 个动作（待机、向右跑、向左跑、挥手、跳跃、失败、等待、工作中、思考），v2 另有 2 行共 16 个视线方向（0° 朝上，顺时针每格 22.5°）。程序内置 74 个可商用的原创形象，图集随后端发布；管理员上传的图集存为本地资源。浏览器只从本站读取图集，不访问任何外部宠物站点。

用户在 Agent 设置「助手形象」里选择后，入口用该形象替代站点形象，选择保存在服务端、只对自己生效；没有选择、失去资格或图集加载失败时回到站点形象。入口逐帧切换背景位置播放图集，按助手状态选择动作（默认：排队与已拒绝为思考、运行中为工作中、等待审批为等待、异常为失败，已完成跳跃一次后回到待机），悬停挥手一次，拖动时按方向奔跑。v2 形象待机时按“头部 → 鼠标”的角度显示对应视线，鼠标停下 2.5 秒或移到形象身上时恢复待机动画。面板打开、页面隐藏或系统开启减少动效时停在第一帧。每行实际帧数在浏览器里按透明度检测一次，读不到像素时使用规范帧数。

内置形象的授权记录在 `backend/internal/agentpet/builtin/NOTICE.md`，随程序分发，不在界面展示。上传形象前应自行确认素材可商用，不要上传名人肖像或第三方 IP 角色。

开放方式有四种：免费；VIP 专享（只对所选分组开放，不能购买）；积分购买（一次性扣费）；累计消费解锁（累计消费达到门槛后免费领取）。后两种可以让所选分组直接免费使用。累计消费与后台用户列表的“已消费”同一口径，只统计已结算的模型调用，购买形象不计入。达标后用户第一次选择该形象时领取，领取记录与购买记录一样长期有效，之后调高门槛或下架都不收回；未达标时卡片显示进度条和“还差 X 积分”。

积分购买的形象可以开限时促销：促销价低于原价，填 0 即“限时免费”一键领取；可设活动名称（默认“限时特惠”/“限时免费”）、开始时间（空为立即）和结束时间（空为手动结束），一次最长一年。促销按服务端时间判断是否生效，购买时在扣费事务里按最新配置复核售价，促销刚结束会提示刷新，不会按旧价扣费。

### 后台管理

「系统设置 → 智能体样式」顶部统计已上架数、付费与会员形象、进行中的促销和累计收入（按实付价格汇总）。列表可按名称 / 简介 / 分类 / 角标搜索，按分类（含未分类）、开放方式、上架状态、促销状态和来源筛选，每行显示分类、上架开关、价格（促销中并列原价）、促销状态与倒计时、拥有人数与收入。列表分页，默认每页 50 个（可选 20 / 100），改筛选或搜索时回到第一页；勾选跨页保留。

- 批量操作：勾选后可上架、下架、设分类、设角标、统一定价与开放方式、按折扣开促销（如 8 折，0 为限时免费）、结束促销、移到最前 / 移到最后、删除。移动时所选形象保持原来的先后，商店里的顺序跟着变。不适用的形象跳过并列出原因，例如给免费形象开促销、删除内置形象或已有人拥有的形象；任一形象校验失败整批不保存。
- 批量导入：一次拖入或选择最多 30 个 ZIP / WebP / PNG，逐个导入并显示结果；触发频率限制时停下，稍后继续导入剩下的。导入完成后自动选中新形象并翻到它们所在的页（新导入的排在最后），方便接着批量设置分类和价格再上架。
- 存储：导入的图集给全站用户使用，不计入导入管理员的账号文件容量，Live2D 模型和形象包也一样。
- 分类管理：分类是形象上的标签，可以整体改名（改成已有分类即合并）或移除（形象变为未分类）；新分类在编辑或批量设置时直接输入即可。内置形象自带猫咪、狗狗、小动物、机器人、奇幻、萌物、人物七类，没保存过配置时使用自带分类。
- 说话风格与台词：上传的形象可以选择说话风格（温柔、猫系、狗系、机器人、魔法、元气）并填写最多 4 句专属台词，和内置形象一样出现在头顶气泡里；不设置时按温柔风格和通用台词说话。内置形象的风格和台词随程序发布，编辑页只读展示。

### 形象商店

Agent 设置「助手形象」和右键菜单的「形象商店」弹窗是同一个列表。顶部显示可用积分（可直接充值）和累计消费；有进行中的促销时出现限时活动横幅，点击只看活动形象。下面按分类和获取方式（可使用、限时活动、免费、积分购买、消费解锁、会员专享）筛选。卡片顶部是按说话风格着色的舞台，左上角是风格和角标，右上角是获取方式（免费、积分购买、几折、限时免费、消费解锁、可领取、VIP 专享、已拥有）；正文是名字、简介、第一句专属台词和醒目的价格行，促销时并列原价、活动名称和倒计时。悬停、聚焦或点一下舞台，形象会挥手并在头顶说一句台词（轮流说专属台词）。窄屏下保持两列。

形象有 9 个及以上时显示搜索框，按名称、简介或分类找（不区分大小写），和分类、获取方式筛选同时生效；搜不到时提示换个关键词。分类和获取方式标签在宽于 420px 的容器里换行全部显示，手机等窄容器保持一行横向滑动。

列表缩略图按需加载：卡片、换形象格子和后台列表缩略图静止时只加载一帧静态 PNG（`GET /agent-pets/:id/preview`，几十 KB），悬停、预览或选中开始播放 150ms 后才下载整张图集（1–3 MB），图集下载好之前继续显示这一帧。从卡片上一划而过、触屏按下就开始滑动都不会下载图集。下载过的图集在本页内直接使用。画布入口、菜单头图和编辑抽屉预览照常直接加载图集。

### 右键菜单与大小

右键点形象身体（或聚焦入口后用系统的上下文菜单键，如 Windows 的菜单键或 Shift+F10）打开形象菜单，菜单在光标处展开，靠近屏幕边缘时向内翻转、超出高度时内部滚动；点外面、按 Esc、调整窗口或切走页面时关闭，Esc 和执行命令后焦点回到入口，方向键可在各项之间移动。

- 顶部名片：当前形象（会动）、名字、说话风格、视线标记和一句台词；默认形象时显示助手名称。
- 快捷块：打开助手、说句话（马上说一句专属台词、贴心话、灵感或时间提醒；待审批提示显示时不可用）、换形象（缩略图格子，列出默认形象和当前可用的形象，可领取的形象有礼物标记，选中即保存到服务端；还没解锁的引导到形象商店）、形象商店。可用形象有 9 个及以上时，换形象顶部有搜索框，规则与商店相同，搜索时不显示默认形象；打开时焦点仍在当前形象上。输入框里左右键和 Home / End 移动光标，上下键回到格子；有关键词时 Esc 先清空，再按一次返回上一级。
- 大小（只在显示宠物形象时出现）：小 96px、中 128px、大 168px、特大 208px，或“自动”跟随站点设置。“自动”时离开画布编辑器或窄屏会封顶到 120px；选定档位后不再封顶，只保证整只放得进视口。大小保存在本机浏览器，与气泡开关一起存在 `yingce:agent_pet_prefs`。
- 头顶气泡开关；收起形象 / 展开形象（收起后小圆球入口同样可以右键）。

### 头顶云朵对话框

宠物形象不显示状态圆点、入口文字和待审批角标，改用头顶的云朵对话框。外形由一圈大小交替的圆弧拼成卡通云朵，带一条弯弯的小尾巴指向形象头顶；白色填充、浅色描边加轻微阴影，暗色主题下同样保持白底。头顶位置取自图集待机帧最靠上的不透明像素，气泡贴在头顶上方，水平方向跟着头部并夹在视口内（四周至少留 16px），尾巴尖随头部位置倾斜；头顶放不下时移到形象左侧或右侧，与头部同高，不会盖住形象。最大宽度 216px，长句自动换行并避免末行只剩一个字。

说话时机：页面打开后约 2.5 秒问候一次；之后每 4–7 分钟随机说一句，内容包括当前时间提醒、仍在运行的生成任务数、未完成的短剧（含最近一部的名称）、上次的画布、创作灵感、贴心话和形象专属台词，连续使用满 60 分钟会提醒休息；运行排队、开始、完成、失败、停止、被拒绝时各说一句；待审批时一直显示，直到审批结束或用户点击收起；悬停时偶尔说一句。普通气泡按字数停留 5–12 秒。面板打开、形象收起、页面隐藏时不说话。“未完成”数据每 10 分钟最多读取一次，任一来源失败只是少一类提醒。用户可在「助手形象」里关闭闲聊，待审批提醒不受影响。内置形象带说话风格（温柔、猫系、狗系、机器人、魔法、元气）与专属台词；上传形象使用温柔风格和通用台词。

## 模型来源与授权

画布入口支持默认动态球、状态动画包和 Live2D。默认状态动画包来自 `web/public/doll/avatar.json` 与其中引用的 MP4；管理页为 Agent 的待命、排队中、运行中、等待审批、已完成、异常、已停止和已拒绝 8 个运行状态分别配置动画，且每项都可选择包内任一 clip。公开视频使用 manifest 的宽高比，客户端对 MP4 逐帧去除绿色背景，活动状态循环播放，终态动画播放一次后停在末帧。媒体层不拦截入口拖动。

动画包在「站点及外观 → 画布配置」导入。ZIP 须在根目录提供 `avatar.json` 和 manifest 引用的 MP4。JSON 使用 `version`、`width`、`height` 与 `clips` 字段；`clips` 的键是动画名，值是根目录 MP4 文件名。导入只创建资源草稿，不自动启用；保存 `avatarBundleResourceId` 和 `avatarClipStates` 后才公开播放。未启用包只允许上传者预览，当前配置引用的包可供管理员预览；配置引用的动画包受资源删除保护。恢复内置动画包或切换动态球不会删除已上传文件，解除配置引用后可按资源管理流程清理。

导入的是已经制作、绑定并导出的 Cubism 运行时模型包，不是立绘图片、PSD 或编辑工程。可以使用自己制作或委托制作且获得授权的模型；项目不提供一键把图片生成 Live2D 的功能。

使用前分别确认模型素材和 Cubism Core 的使用、部署与分发授权。启用后浏览器需要取得模型资源，无法承诺防下载；不应上传需要保密的素材。

## 部署运行库

前端使用固定版本 `pixi.js@6.5.10` 和 `pixi-live2d-display@0.4.0`，按需加载 Cubism 3/4 渲染适配器。Cubism Core 已纳入仓库的 `web/public/live2d/live2dcubismcore.min.js`，随前端构建及静态镜像发布，无需部署者另行安装。不从第三方 CDN 加载，也不接受模型 ZIP 中的脚本。Core 保留原始版权与许可声明，不适用本项目的 MIT 许可证；参见同目录 `NOTICE.txt`。

1. 使用前确认 Live2D SDK 及模型素材的适用授权；内置运行库不代替部署者对使用场景的授权确认。
2. 拉取包含运行库的提交并重新构建前端，或部署由该提交构建的新镜像。Vite 将 Core 复制到 `dist/live2d/live2dcubismcore.min.js`，Docker 镜像中对应 `/usr/share/nginx/html/live2d/live2dcubismcore.min.js`。旧镜像不会因拉取源码自动更新；已有同路径挂载时应检查是否遮蔽内置文件。
3. 确认同源 `/live2d/live2dcubismcore.min.js` 返回 JavaScript 而非 SPA 页面。非根路径部署跟随前端构建 BASE_URL。
4. 后台导入并预览，成功后选择 Live2D，点击顶部「保存修改」。导入本身不启用；失败不更改当前形象。

部署产物遗漏 Core、模型不兼容、网络超时或 WebGL 上下文丢失时，入口回退默认动态球，仍可点击打开 Agent。后台显示错误并提供重试。未使用具有适用授权的真实模型验证时，不能仅凭构建成功认定播放验收通过。

接入层支持旧版 `drawables.renderOrders` 和新版 Core 的 `Model.getRenderOrders()` 绘制顺序接口，不修改 Core 文件。当前 Cubism 4 渲染适配器不支持新版离屏渲染对象；此类模型会明确报错，而不是忽略对象后显示不完整形象。

## 状态动画 ZIP

- 压缩包最大 128 MiB，解压总量最大 384 MiB，最多 128 个条目；单个 MP4 最大 64 MiB，JSON 最大 2 MiB，最多 64 个 clip。
- `avatar.json` 须位于根目录，结构示例：

```json
{
  "version": 1,
  "width": 480,
  "height": 432,
  "clips": {
    "idle": "mascot-idle.mp4",
    "working_loop": "mascot-working-loop.mp4",
    "think": "mascot-think.mp4",
    "wave": "mascot-wave.mp4",
    "wipe_sweat": "mascot-wipe-sweat.mp4"
  }
}
```

- `width` 和 `height` 范围为 1–4096；动画名只能包含英文字母、数字、下划线和连字符。每个 clip 必须引用唯一的根目录 MP4，ZIP 中不允许未引用视频或其他用户文件。`.DS_Store` 与 macOS `__MACOSX` 元数据会忽略。
- 不允许路径穿越、嵌套文件、软链接、重复或大小写冲突的文件名。后端会检查 manifest、ZIP 边界和 MP4 文件头；实际画面和动作映射应在管理页预览确认。

ZIP 保存在本地资源目录，不解压到磁盘；浏览器只可读取当前启用包中的 manifest 和 MP4，支持 MP4 Range 请求。

## Live2D ZIP 要求

- 压缩包不超过 128 MiB，解压累计不超过 384 MiB，最多 256 个条目；单文件不超过 128 MiB，JSON 不超过 2 MiB。
- 只能有一个 `*.model3.json`，`Version` 为 3，所有引用必须位于 ZIP 内且使用规范相对路径。
- 包含 `.moc3` 和 1–8 张 PNG 纹理；单张不超过 4096 × 4096，包内纹理总像素不超过 32 Mi 像素。
- 可带动作、表情、物理、姿势等 JSON；不支持 Cubism 2、音频引用、脚本和编辑工程。请移除 README、缩略 JPEG、系统隐藏文件等无关文件后打包。
- 不允许外部 URL、路径穿越、软链接或大小写冲突的路径。后端验证结构和边界；MOC3 与 Core 的实际兼容性由预览确认。

Live2D ZIP 作为本地 `live2d` 资源保存，不解压到磁盘。草稿只有上传者可预览；当前配置引用的模型允许其他管理员预览。只有已启用模型的指定数据文件允许公开读取。启用时服务端重新检查并决定入口，不信任客户端提供的入口路径。

## 行为与清理

- 高度可设 120–360px，画布入口按视口缩小并限制拖拽边界，保留点击打开、鼠标拖动和方向键移动。
- 渲染上限为 30fps；后台标签页及不可见预览暂停更新，减少动态效果偏好下只渲染静态形象。首期不含口型、语音联动或点击表情交互。
- 选择默认球不会删除模型引用；清除引用并保存后，可到资源管理清理。放弃未保存导入的包也可在那里清理。
- 引用中的包受资源删除保护。恢复默认外观也会恢复画布配置，但不删除文件。
- 配置存于 `system_settings` 的 `appearance` JSON（合同版本 11），不新增表或数据库迁移。一起更新前后端；降级前备份设置及资源，不用旧后台覆盖新配置。
