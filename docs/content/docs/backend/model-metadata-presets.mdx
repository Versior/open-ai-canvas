# 模型资料预设

后台「系统渠道 → 模型管理 → 新增/编辑模型」的基本信息区提供「模型参数预设」和「复用完整模型配置」。新增模型输入 ID 后继续使用自动匹配；已有模型可点击「自动识别并填写」。选择文本预设后自动填入参数，空白产品标识、上游 ID 与渠道展示名使用所选模型 ID，已有标识保留。所有操作先填写表单，保存后生效。

## 完整配置复制

选择当前或其他系统渠道的来源模型，预览会列出将替换的内容。点击「复制完整配置到表单」可复用能力、调用协议、整套引用限制与协议参数（含素材传输方式）、价格档、成本、Token 分时/上下文规则、计价货币、参考视频计费，以及分组、Logo、标签和描述。支持替换未配置或已配置模型。

目标产品标识、上游模型 ID、渠道展示名与启停状态保留。默认将每个价格档的请求绑定到目标模型；勾选「同时复用独立上游 SKU」后，独立 SKU 会使用来源 ID，管理员须确认目标渠道确实支持。来源模型的记录 ID、价格档 ID、版本及渠道凭据不复制。来源协议不可用时禁止复制；保存沿用现有后端能力、价格和管理员权限校验。

## 主动识别模型

「自动识别并填写」从当前渠道相同型号的已配置模型、文本资料快照、已声明的协议工作流和上游模型目录读取资料。图片、视频可填入上游声明的引用数、时长选项、画幅、分辨率及默认值；工作流与图片参数继续复用现有协议解析器。

「读取上游目录」通过管理员接口 `GET /api/admin/channels/:id/model-metadata` 使用服务端保存的凭据访问固定模型目录，不需要在浏览器重新提交密钥，不导入模型。选择目录中的模型后自动识别并填写；已存在的产品标识作为别名保留，上游 ID 使用所选条目。

未声明的参数保留当前配置或明确沿用已选协议的默认值，不作为供应商能力上限。无法识别型号、候选配置冲突或多个协议无法确定时提示手动选择，失败不写入表单。目录或文本快照读取失败会明确提示；有可靠本地资料时可继续填入。主动识别保留价格、计价货币、启停状态及自定义展示资料，能力或参数变化后提示核对价格。识别不触发收费模型测试。

## 自动新增与配置复用

手动新增、后台批量导入、渠道初始模型同步、个人渠道手动添加及拉取模型均接入自动配置。后台导入将模型及价格档在同一事务保存；重复导入不改已有模型，新增导入项仍默认停用，核对价格后再启用。个人渠道只补充没有配置记录的模型，已有人工配置保留。

接口与价格优先参考当前渠道相同型号，找不到时可参考同系列、同规格的已配置模型；最高匹配等级存在多个候选时不随意选取。复用包括计费方式、输入/输出/缓存价格和已有价格档，后台价格档使用新模型的上游 ID，不沿用旧型号。这里复用的是本渠道配置，不是官方报价，也不会复制连接地址或凭据。跨版本系列匹配只参考接口与价格，不将旧版本的能力上限当成新版本资料。

新增表单手动修改过的能力、协议、参数、图标和价格优先保留。换成无法匹配的名称时，清除上一次自动填写的参数和价格，价格标记为未配置，避免误留旧值。缺少可靠匹配时需要手动配置。

分类与 Logo 独立于文本能力快照匹配。新增模型优先沿用唯一同类配置的分组和图标，否则按归一化的模型家族名称填写；图片、视频型号无需匹配到文本上下文资料。未知家族保留未分类与空 Logo，不根据渠道供应商猜测。手动修改分类和 Logo 后不再自动覆盖；修改模型 ID 时清除上一次自动匹配结果。后台导入和个人渠道新增也填写分类与 Logo，已有记录不批量改写。

价格区支持选择当前或其他系统渠道中同能力的模型，点击「复制价格到表单」复制售价、成本与计费方式。带规格条件的价格要求相同协议，复制后仍需核对当前模型支持范围；不会转换价格单位，也不会复制来源模型的上游 ID。保存后生效。

## 能力数据与来源

预设来自 [Pi 模型目录](https://pi.dev/models) 的公开机器可读目录，随前端保存为独立懒加载快照。快照包含抓取时间和原始响应 SHA-256；不包含价格、地址、请求头或凭据，不在运行时向外站发送渠道配置。保留上游 MIT 许可。

应用操作更新文本模型的上下文窗口、最大输出 Token、图片引用数量，并在 Logo 为空时填入本地图标库的品牌图标。已有 Logo、描述、标签、模型 ID、展示名、协议、价格、成本和启停状态保留。流式、思考开关、单图字节上限、视频引用和提示词字符限制不根据目录推测。目录的推理能力仅展示，不等于当前协议支持用户切换思考模式。

匹配依次比较完整名称、忽略大小写与命名空间后的规范名称、去除常见推理档位或日期后缀的名称；支持空格、点、下划线和短横线差异。版本数字和 Flash、Pro、Mini 等规格保留，不跨版本猜测上下文。同等级优先无命名空间的型号资料；同 ID 重复条目窗口、输出和已声明图片数量取最小值，图片与推理能力取交集。这是保守预设，不宣称是厂商原生上限。图片输入不代表图片生成，不将这些文本能力应用到图片、视频或音频生成模型。

图片数量采用目录明确声明的值，但受当前应用最多 100 张限制。目录缺少数量时保留已配置数量；没有配置则以 1 张作为界面明确说明的初始使用策略，不能称为供应商原生上限。纯文本模型应用后图片引用数设为 0。Pi 的图片 resize 字节阈值不作为原生单图限制。

窗口或输出数值超出当前配置校验范围、输出不小于上下文窗口时，保留原始预览，禁止直接应用并提示手动核对，不通过截断数值掩盖口径差异。

## DataLearner 分析

[DataLearner 模型列表](https://www.datalearner.com/ai-models/pretrained-models) 可补充中文分类、发布日期、开源许可、官方模型卡和评测资料。其[数据收集方法](https://www.datalearner.com/about/data-methodology)声明优先采用官方数据，再采用基准官方结果与第三方评测。列表同时包含传闻模型；详情也可能列出历史别名，不能直接作为可调用 ID 映射。当前没有批量复制该站介绍或评测数据，配置表不显示该站入口。

实际核对 [DeepSeek V4.1 Flash 详情](https://www.datalearner.com/ai-models/pretrained-models/deepseek-v4-1-flash)时，页面说明上下文为 1,048,576、最大输出为 393,216 Token；本次 Pi 快照里部分转售供应商条目为 1,000,000 / 384,000，另一供应商最大输出为 32,768。这说明 K/M 口径和渠道限制均可能不同，不能跨供应商直接合并。应沿详情页的官方出处继续核实，并以实际渠道合同为准。

目录或评测分数不证明中转渠道当前可用，不触发付费测试。新增模型的价格仅在明确匹配到已有配置时复用，已有模型价格不自动调整。预设不能修复上游 HTTP 503。

## 维护

在仓库根目录运行 `node scripts/update-model-metadata-presets.mjs` 更新快照。脚本只读取固定公开目录，校验后同步生成前端懒加载快照和后端嵌入快照，两份数据由测试检查一致性。管理员打开模型编辑页、用户打开个人渠道设置时加载前端目录。更新后运行模型预设专项测试及前端构建。
