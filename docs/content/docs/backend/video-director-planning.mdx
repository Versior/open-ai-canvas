# 视频复刻导演策划

原来的工作台只改口播，导演设置主要是平台和拍法的一句提示。现在「换成我的」配方中的「AI 导演策划」先输出全片决策，再落实到重拍镜头；拆解记录中的「改写脚本」启用导演后也输出完整策略。

## 平台与拍法

共用知识模块 `web/src/lib/canvas/replica-director-knowledge.ts` 为八种平台提供开场、证据、节奏、收束和交付建议：抖音、小红书、快手、微信视频号、TikTok、YouTube Shorts、Instagram Reels、亚马逊商品视频。

拍法包括真实演示、人物情境故事、商业棚拍、创作者口述与上手、开箱、步骤教程、条件对照、材质与工艺特写、生活方式场景、问答选购、定格陈列、纪实过程。默认让模型依据商品、观众顾虑、原片与可改镜头选择，并说明理由。叙事组织单独选择，不强制每条视频使用「钩子、痛点、演示、证明、购买」五段。

这些条目是可维护的创作建议，不是平台审核规则、实验结果或流量保证。当前直接核对的官方资料只有以下两项，其余条目不能冒充官方政策：

- [TikTok 效果广告创意建议](https://ads.tiktok.com/resources/help/article/creative-best-practices?lang=en)：声音、竖屏、清晰度和界面安全区域等建议，适用范围为效果广告创意。
- [YouTube 三分钟 Shorts](https://support.google.com/youtube/answer/15424877?hl=en)：方形或竖屏的分类与时长、超过一分钟且存在有效版权声明的限制。不能据此推导观看或转化效果。

## 策划结果与商品分析

每版包含观众与购买角色、具体顾虑、核心主张、可见钩子、拍法、叙事、商品及平台的选法理由、原片取舍、场景色调布光、声音剪辑、收束与待补资料。儿童用品按实物与用途选择氛围，不默认灰调。

工作台一次比较两至三个方向，选用前保留逐镜编辑。已有正在使用的方案时保留该版，并比较两个新方向；最多保存三版。结果数量不足、结构缺失、口播超时、镜头重复、未知证明依据或动作描述超限会拒绝应用，不截断动作冒充完整策划。

支持图片且符合输入数量限制的策划模型会收到商品图资源，按原顺序使用其可接受的前若干张。纯文本模型仍可依据文字档案与原片拆解策划，页面明确标示当前输入范围；没有图片时禁止声称看过实拍。图片可帮助辨认外观和颜色，不能证明材质成分、性能或操作方法。模型返回的拟拍动作和使用说明仍需与实际商品核对，不能把缺资料转化成确定效果。

## 逐镜执行边界

| 工作台做法 | 策划可修改的内容 |
| --- | --- |
| 重新拍 | 本镜用途、动作前状态、动作过程、结束状态、景别、机位、布光色调、依据、声音意图、口播和画面字 |
| 换元素 | 适配口播，动作、机位与节奏仍由原参考视频约束 |
| 保留原片 | 策划不改现有逐镜编辑，使用原片仍需授权 |
| 删掉 | 不计入策划与成片 |

导演不能自动修改做法、时长、镜头编号、授权或音频模式。证明依据只能逐字引用一条商品卖点；编号清理保留「12 小时保温」这类数值事实。画面字交给剪辑，不要求视频模型生成精确文字。

选用后，重拍视频请求包含已选全片策略和完整逐镜导演描述，首帧与动作使用同一方向。换元素请求只受连续性约束，不被新剧情覆盖。策略、动作、布光或证据变化会影响生成单元的创意签名，保留原候选并重新生成受影响单元。

## 保存、过期与费用

工作台作品在既有 `productVideos` JSON 内保存 `campaign`、`directorPlans` 和 `activeDirectorPlanId`，无需数据库迁移。导演版本记下商品、平台、人物场景、音频语言、补充要求、原片解读与逐镜做法的输入快照。输入改变后旧版可回查，但不能继续选用或带入新生成；可取消过期绑定，保留逐镜编辑。

保存沿用作品 revision 的比较交换，冲突不会覆盖其他窗口。作品仍受单条 128 KiB 的既有限制；导演版本最多三份，输入快照最多 64 KiB。后端校验平台、拍法、完整策略、全部保留镜头、动作始末、做法边界和原文证明依据。

策划走普通文本任务与账号费用，不自动重试，不自动选用，也不自动生成视频。取消、卸载和账号切换沿用任务边界，阻止把返回结果写到其他账号。

## 验证范围

专项回归包含策略保存重载、实际提示词、商品与平台变化、过期方案、原动作保护、真实组件提交和手动选用；后端检查包含完整方案保存重读及 revision 冲突。

直接渠道实测使用虚构商品档案，分别比较儿童眼镜与亚马逊折叠支架的两版策略。最终四版通过前端结构及事实引用校验，儿童方向使用明亮暖色或中性色，支架方向采用中性台面或办公环境。首轮实际回复暴露编造操作步骤与保留镜头说明冲突，已据此收紧提示。后续回复仍可能在全片说明或口播中给出未证实的调节建议，结构校验不能替代操作核实与策划质量评审。

真实用户商品的看图策划效果、登录态布局和实际成片仍需验收；不把文本输出或构建通过算作成片质量通过。
