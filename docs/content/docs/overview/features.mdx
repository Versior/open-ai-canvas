# 功能清单

电商 Agent 支持SHEIN（希音）及逐平台风格、风险资料与生成文案检查；资料覆盖范围及尚待核实的上架条件见[电商平台风格与图片规则](/docs/overview/ecommerce-platform-rules)。

## 旧版电商画布（已下线）

旧版电商画布已删除：`/ecommerce/canvas` 列表、画布种类区分、十四种电商节点（商品、拍法、卖点、文案、品牌风格、排版、信息图、爆款复刻、竞品拆解、交付、改稿、电商视频、A+ 内容、画布内电商生图台）、电商创作表、模特库与套图面板都不再提供。旧地址 `/ecommerce/canvas` 重定向到 `/canvas`。

- 存量电商画布（`kind: "ecommerce"`）和自由画布在同一个画布列表里，按自由画布打开。
- 画布里的电商节点和旧电商创作表显示「已下线」占位，写明原节点类型；不能连线，不参与生成和生成恢复，节点数据原样保存。
- 批量创作表的「电商创作」模式（`product`）属于通用批量表，继续保留，见下方「批量创作表」。
- 商品出图改用左侧导航的「电商生图台」（见下方「电商生图台」一节）；对话式出图用 `/ecommerce` 的电商 Agent，见 [电商 Agent 与知识库](/docs/backend/ecommerce-agent)。
- 后台 `/admin/settings/ecommerce` 改名「电商生图台」，只编辑「商品档案」能力的开关与指令，以及 EcomGen 套图模板。内置 1173 套模板仍可检索、预览、载入草稿或导入 suite v1 JSON；启用的模板会出现在生图台「模板套图」的后台精选里。

## 游客浏览与登录弹窗

未登录也能打开首页（`/` 与 `/create`）：看到模型列表与价格（默认分组）、画布灵感与精选作品，并能打开作品详情。生成、上传、打开素材库、新建画布、Agent 创作和「复制到画布」会弹出登录弹窗，不会提交任务。

登录弹窗用上游的共用登录面板：左侧是品牌区（品牌名、登录页主标题与说明），右侧是登录 / 注册 / 找回密码面板，与 `/login`、`/register`、`/forgot-password` 页面是同一套表单，「忘记密码？」在弹窗里切到找回密码。游客打开网站时，每个浏览器会话自动弹出一次，可关闭；后台把登录入口设为「独立页面」时不自动弹出。上面这些需要账号的操作始终用弹窗，登录成功后弹窗关闭，留在当前页，已写的提示词保留。`/login` 页面照常可用。

## LibTV 灵感广场

首页精选灵感提供“画布灵感”和“单次创作灵感”切换。登录用户可在灵感广场搜索、按标签筛选和分页浏览 LibTV 公开作品，查看成片、制作步骤、公开提示词及图片、视频、音频预览。
可独立复用的步骤支持预填到创作页，不自动生成；含引用的模板可复制到新画布，预览转换警告并确认导入，保留节点、连接、画框和多个媒体结果。公开作品查询不需要管理员的 LibTV 凭证；原有私有项目导入设置保持独立。
## 画布姿势库

- 画布底部工具条、添加节点菜单和右键菜单打开「姿势库」，按体系、分类、视角筛选和搜索，卡片内切换视角，多选后插入为图片节点，再连到生图节点作为姿势参考。
- 姿势数据由站长在后台导入：支持 [ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh) 的 `data/pose-zh.json` 与影策通用姿势包，也能逐张新增。代码仓库不含图片，服务器把图片同步到本站数据目录；成人向体系默认不导入。
- 插入时把原图复制成用户自己的资源，生成任务、下载和分享按普通图片处理。详见 [姿势库](/docs/canvas/pose-library)。

## 用户分组与多币种计价

管理员在后台「用户与运营 → 用户分组」维护分组（例如 default / vip / svip）：设置分组倍率（1 为不打折，0.8 为 8 折）、「1 USD / 1 CNY = N 积分」兑换比例、可用的系统渠道（或开放全部渠道），以及单个模型的倍率和兑换比例。再在「用户管理」的编辑抽屉里给用户分配分组，列表可按分组筛选。用户只能看到并使用所属分组绑定渠道下的模型，价格按分组换算后展示和扣费；管理员账号可见全部渠道。分组可选 VIP（金色）或 SVIP（紫粉流光）徽章，用户端头像、侧栏和账户卡片会展示对应徽章与头像光环。

渠道模型的「积分定价」页可选择计价货币：积分、USD 或 CNY。货币计价时售价按货币填写，扣费时按用户分组的兑换比例换算成积分。「支付充值 → 充值商品」可选择默认充值货币（CNY / USD，默认 USD）并填写 USD/CNY 汇率，每个商品也可单独设定售价货币。支付渠道按自己的结算货币收款（易支付可设为 CNY 或 USD，其他官方渠道为 CNY）；商品货币不同时按汇率换算实付金额，充值面板显示“约付”金额，订单保存实收快照。易支付可同时启用支付宝、微信、QQ 钱包、USDT 等支付方式，并支持 `submit.php` 页面跳转。接口与数据结构见 [HTTP API 合同](/docs/backend/http-api) 和[后端数据库](/docs/backend/backend-database)。

## 短剧插入与删除集

制作台左侧分集列表的每一行右上角有「更多」按钮（悬停、聚焦或当前集时显示，触屏常显），提供「在前面插入一集」「在后面插入一集」和「删除本集」。末尾追加仍用列表顶部的加号或底部「添加第 N 集」。

- 插入：打开与追加相同的原文编辑弹窗，新的一集取得插入位置的集号，后面各集集号顺延；已做好的集内容不受影响。新原文排在相邻集的原著章节之间，造型的默认适用章节号随之后移，仍对应原来那些章节。没填标题的集（“第 N 集”）和队列里的工作名称会跟着改号。
- 删除：本集的剧本、分镜、剧情段、段视频与成片的版本一并删除，后面各集集号前移一位；只属于这一集的原文退回「原著章节」，之后可以重新加入制作。本集生成过分镜视频（包括重新改编前的旧视频和成片）时，需要输入“第 N 集”才能删除。本集还有已提交的生成任务、作品只剩一集或仍在分集规划时不能删除。
- 样片模式以第 1 集为样片：在第 1 集前插入或删除第 1 集会改变样片集。

接口见 [HTTP API 合同](/docs/backend/http-api)，数据变化见[后端数据库](/docs/backend/backend-database)。

## 短剧精修画布

短剧自动制作是事实源，关联的画布是精修台。每部短剧有一张精修画布：制作台顶栏「精修画布」、本集「在画布中打开本集」、设定详情与剧情段弹窗里的「在画布中精修」、成片页「到画布精剪」都会打开它（没有时自动新建并关联），并把对应对象投送过去。画布左侧的短剧侧栏列出设定与分集，可以按设定、单个剧情段、整集或成片投送，已投送的对象点击即定位；底部显示已用积分（含画布精修）与预算。

- 投送：设定是一张带外观描述的图片节点，历史参考图作为节点版本；剧情段是一个段框，内有短剧提示词参考副本、按“参考图N”顺序连到视频的参考图、首帧（上一段尾帧）、带完整提示词的视频节点与本段镜头表，可直接在画布上换首尾帧、延长或重新生成；成片是视频节点，「剪辑」把各段视频按成片顺序载入画布时间线精剪。投送的媒体由服务端登记为素材（我的素材里能看到），不复制文件。
- 采用：图片或视频节点的工具栏与右键菜单提供「采用到短剧」，写成短剧的一个新版本。设定参考图采用后锁定，可选让引用它的剧情段重新生成（画布里默认不勾选）；剧情段视频默认只换本段，也可让后续已生成的段以新视频尾帧重新生成。采用前提示画幅、音轨、时长差异与本段是否正在生成；段刚被修改时拒绝并要求刷新。
- 过期提示：短剧侧有更新的版本（流水线重新生成、制作台上传或其他画布采用）时，画布节点显示「短剧已更新」，点击或用工具栏「同步短剧」换成最新版本，画布上的画面保留在版本历史里。
- 版本记录：制作台的设定与剧情段显示版本记录，标出来源（生成、上传、来自画布）与当前版本。
- 预算：画布上生成任务的花费计入短剧预算与已用积分，预算用完后精修画布也不能再提交生成。
- 反向：画布分镜脚本节点右键「交给短剧自动制作」，按分镜原样转录为新短剧；未关联项目的画布在创建后成为它的精修画布。
- Agent：关联短剧的画布上，Agent 多出读取短剧上下文与「采用到短剧」两个工具，采用总要审批。

接口见 [HTTP API 合同](/docs/backend/http-api)。

## 短剧导出剪映草稿与资产包

- 导出剪映草稿：成片页「导出剪映草稿」把本集已生成的剧情段视频按成片顺序排在主轨上，可附带按分镜时长估算的台词字幕轨（另附 SRT）。首次需要填写剪映专业版的草稿目录（剪映「全局设置 → 草稿位置」），之后记在本机浏览器。下载的压缩包解压到该目录，重新打开剪映即可在首页草稿列表里打开。剪映 6.0 起会加密自己保存的草稿，但能打开外部生成的明文草稿。
- 一键打包全部资产：制作台顶栏「资产包 → 一键打包全部资产」选择已拆解分镜的剧集，可分别勾选媒体文件（设定参考图、声音样本、段视频、成片）和提示词（Markdown）。全剧设定总会打包，导出不消耗积分。
- 导入资产包：「资产包 → 导入资产包」选择影策导出的压缩包，按类型与名称匹配当前作品的设定，替换参考图（旧图留在版本记录里）、可选覆盖外观与简介；按集号与段号把段视频提示词写成自定义提示词，分镜数量一致的集还可导入镜头画面与运动描述。先预览将写入与跳过的项再执行，视频与声音样本不导入，已生成的段视频不会自动重做。

接口见 [HTTP API 合同](/docs/backend/http-api)。

## 分时与上下文 Token 价格

渠道模型「积分定价」页在文本模型下多出「分时与上下文价格」：选择一个 Token 价格档，打开「启用扩展」后按星期、时段（上海时间）和输入上下文 Token 区间添加档位，每档单独设置输入、输出、缓存读取、缓存写入单价，例如夜间优惠价或 32K 以上长上下文加价。任务创建时锁定时段，结算时按上游真实输入 Token 选档，都未命中时使用基础价格。用户端模型选择器的价格区间包含规则单价并标注「分时」，悬停可看各档说明。数据结构见[后端数据库](/docs/backend/backend-database)。

## 短剧并行出片与 WAN 3.0 拼车中转

短剧制作设置与新建页新增「段落衔接」：

- 尾帧续接（默认，原有行为）：第 2 段起用上一段视频最后一帧做首帧，同一集按顺序逐段生成。
- 并行出片：每段只按角色、道具、场景参考图独立生成，不带首帧、不等上一段。同一集满足条件的段一起提交，实际同时生成数受「同时生成数」和账号活动任务上限约束。段视频提示词不再要求段尾硬定格；画布「采用到短剧」只替换本段，不提供级联重生成。只支持参考图生视频、不支持图生视频的模型只能用并行出片，保存设置时会校验。

「同时生成数」对文字（资产提取、分集规划、剧本、段提示词）、参考图、段视频和成片合成分别计算，正在生成的段视频不占提示词和参考图的名额。排队顺序先按集号：前面的集整体优先，同一集内按成片、剧本、段提示词、段视频排序。排队还没提交的工作会显示原因（作品暂停、账号同时任务已满、本类同时生成数已满及前面还有几项），剧情段卡片和队列面板都能看到。段视频完成后尾帧在后台抽取，不阻塞其他作品派发。

## 短剧步骤配置、表演运镜与视频分辨率

- 文字步骤：资产提取、分镜拆分、视频提示词每一步可以单独选文本模型和写作技能（来自「我的技能」），不选就用默认文本模型和内置写法。资产提取与分镜拆分的输出结构由系统固定，技能只决定取舍和写法。要微调写法，在技能库里改自己的技能，下一次执行就读新内容。
- 参考图：角色、道具、场景可以分别选图片模型与分辨率档位，不选沿用默认图片模型。设定详情除了上传形象图，也可以从素材库选图片（角色还可选角色卡的当前形象），选中后替换并锁定。
- 镜头节奏改为五档滑杆（极快 / 快 / 标准 / 舒缓 / 慢），新作品默认快节奏，转场时长默认 150 毫秒。
- 分镜规则新增「表演强度」（内敛 → 克制 → 自然 → 饱满 → 夸张）与「运镜动感」（静态 → 稳定 → 标准 → 动感 → 强烈）两个 1–10 档滑杆，写进剧本与段视频提示词的表演、台词语气和运镜要求。尾帧续接的段末只收势 0.5 秒，不再整段硬定格。
- 新建页与制作设置可以选剧情段视频分辨率，档位来自所选视频模型；按段或批量换模型时，给不出该分辨率的模型置灰。
- 段视频提示词按视频模型的提示词上限撰写，超出时自动精简；剧情段弹窗显示发送全文字数与上限。

管理员可以安装官方插件「WAN 3.0 拼车中转（班次发车）」（`coolhs-wan3-relay`），把 `wan.coolhs.com` 的 `/api/portal` 接口配置成系统视频渠道，卡密写在渠道 API Key 里。插件的处理流程：

- 素材：先上传参考图、视频、音频拿到素材 ID；短剧的“参考图N”原样作为素材 token。
- 交单：用平台幂等键作为任务 `id`，有参考素材时关闭官方扩写。
- 等待：提交后释放执行位，每 15 秒回查一次，任务进度显示“候车 · 前面 N 条 / 已发车 / 出片中”。
- 出片：成片链接是临时地址，出片后立即下载转存。

中转站的首尾帧不能与参考图混用，短剧使用该渠道时请选择并行出片。插件字段见 `plugin-packages/coolhs-wan3-relay/docs/interface.md`，宿主能力见[统一插件运行时](/docs/backend/protocol-plugins)。

## 推广中心

管理员在后台「用户与运营 → 推广中心」开启推广，并选择开放方式：「全民推广」让所有正常账号看到推广中心、推广链接和推广收益；「指定推广人」只开放给在「用户管理」中打开「推广人」开关的账号。用户从账户菜单进入 `/referral`，复制 `/register?ref=推广码` 链接；新用户通过链接注册后归属推广人。被邀请用户每笔积分充值到账后，推广人按后台设置的比例（0%–50%）获得积分返佣，并在推广中心看到邀请记录、返佣记录和累计收益。存储空间订单不返佣；Linux.do 等第三方首次登录建号暂不记录推广来源。数据结构见[后端数据库](/docs/backend/backend-database)。

## 画布多窗口实时协作

同一账号在多个窗口打开同一画布时，在画布顶部正中间以紧凑入口显示在线设备数量，展开后查看“设备1、设备2”等会话。服务端统一编号，各窗口名称和颜色一致，自己所在行标记“此窗口”。只显示远端光标的小标签和轻量拖拽轮廓；只剩一个窗口时全部隐藏并停止采集光标。高频坐标按帧直接更新独立浮层，不触发 React 重渲染。WebSocket 广播临时预览和提交后的同步通知，最终内容仍经过原有 operations 保存与并发合并；正常空闲连接改为低频状态校验，断线保留轮询。未配置 Redis 支持单后端进程，配置后支持跨实例分发；不增加跨账号编辑权限。真实浏览器与部署验收见[待测试](/docs/progress/pending-test)，协议见[画布操作同步](/docs/backend/canvas-operations-sync)。

## 用户登录日志

管理员在“用户与运营 → 用户登录日志”查看密码、邮箱/短信验证码、Linux.do 的成功/失败登录、注册自动登录和主动退出。支持用户、事件、方式、结果、IP、时间范围筛选、分页、刷新、详情和失败重试；显示账号快照、设备信息和安全原因。成功记录与会话操作原子提交，重复/伪造/过期退出不产生成功事件；刷新和自然过期不计为登录/主动退出。普通用户不可访问，不记录密码或会话凭据，不补造历史。

## 用户意见与反馈

## 设置页分组与偏好设置

## 生成完成提醒与标签页标题

图片、视频、音频、分镜生成和时间线导出成功时，右上角弹出通知：成功圆圈弹入、对勾描绘一次，带结果缩略图、所在画布名和提示词开头；不在该画布时可点「查看画布」，其余任务可「查看任务」。同时播放一声约 0.5 秒的提示音（Web Audio 合成，无音频文件；浏览器要求先有一次点击或按键才能出声）。同一批在 0.6 秒内完成的任务合并成一条通知、一声提示音。Agent 内部步骤和普通文本对话不提醒。两项默认开启，可在「设置 → 偏好设置 → 通知」关闭；减少动态效果时不播放动画。

只有本标签页见过「排队 / 运行中」的任务变成成功才提醒，每个任务一次；打开创作历史时已经结束的任务不补发。离开画布等页面后，页面自己的轮询停止，全局提醒每 10 秒查询仍在运行、且 12 秒内没人刷新过的任务（最多 8 个，最长跟踪 3 小时）。标签页在后台时先出声，标题前加「(2) 生成完成 ·」，图标右上角加成功色圆点；回到页面后清除，并补一条汇总通知。跨域 Logo 没有 CORS 时只保留标题提醒。

浏览器标签页标题显示当前页面：画布页为「画布名 - 品牌名」，重命名后立即更新；短剧制作台为项目名；设置页为「分类名 · 设置」；其余工作台页面为导航名称，与顶栏面包屑共用 `web/src/lib/workspace-page-title.ts`。管理后台和未识别的页面仍用后台配置的 SEO 标题。

- `web/src/services/generation-completion-tracker.ts`：汇总任务创建、详情、列表和订阅读到的状态，判断「刚完成」。
- `web/src/components/layout/generation-success-notifier.tsx`：通知、提示音、后台补发和离开页面后的低频查询。
- `web/src/services/tab-attention.ts`、`web/src/hooks/use-workspace-document-title.ts`：标签页提醒与页面标题；标题仍由 `use-appearance-store` 统一写入。

## 卡藏 Midjourney

画布接收一次任务返回的全部图片，四张结果自动组成收起的图片堆叠，可展开、选择主图和分别使用。每张图保留独立资源及素材绑定，保存、刷新和任务重复同步不会将后续图片覆盖为第一张。已有仅显示首图的成功 Midjourney 节点在重新打开画布时从原任务恢复遗漏结果，无需再次生成。

特惠使用标准图片端点，稳定/高速使用受理和任务查询端点。结果支持顶层与 data 信封，全部单图及可选四宫格封面交给宿主立即保存；失败和空结果保留真实失败语义。完整模型和字段合同见插件包内 `docs/interface.md`。

## 存储空间套餐

## 沧元 Midjourney

`cangyuan-midjourney` 声明式插件分别提供 V7 与 1K/2K（供应商默认 V8.2）协议。V7 使用 `midjourney-v7`；1K/2K 使用 `midjourney-1k`、`midjourney-2k`，可在提示词显式写 `--v 8.2`。一次提交固定 `n=1`，全部结果交由宿主下载保存，参考图按供应商合同发送 HTTPS URL 字符串。

两条线路的参数、编辑端点和响应格式分别适配，不自动换模型。1K/2K 返回官网 CDN 原链，HTTP 403 会如实保留保存失败与原任务重试能力；插件不能消除供应商 CDN 的访问限制。完整字段与接口合同见插件包内 README 和 `docs/interface.md`。

创作页按整个任务一次消费返回图片，保留各图片的输出序号；一次请求返回多张时，素材与消息幂等去重不会再把后续结果当作第一张合并。

后台选择这两个协议时，“能力与参数”自动使用线路专属默认值：V7 为 4000 字符、五张参考图、不支持蒙版；V8.2 默认单张编辑源图、支持蒙版和十五种比例。两者默认自动尺寸、一次提交，关闭不支持的质量、透明背景、响应格式和输出格式选项。V8.2 在模型名未明确时暂用 1K，识别到上游 `midjourney-2k` 后改为 2K，切换档位保留管理员的参考限制、默认比例和价格。像素预设由宿主换算供页面展示，提交上游仍使用比例，实际尺寸由供应商决定。

## AutoDL 画面规格

AutoDL 视频模型的上游模型 ID 原样透传为 ComfyUI 工作流 ID，上线新工作流无需更新插件。“能力与参数 → 画面规格”多选完整分辨率并设置默认值：插件 v2.4.0 已声明的工作流使用各自预设，其他工作流默认提供 480p竖、768p竖、960p竖、480p横、768p横、960p横（默认 768p竖），也可直接输入上游支持的其他标签。未声明工作流的请求把全部参考图编号为 `ref_image_N`、参考音频编号为 `ref_audio_N`，数量由模型能力中的参考限制控制。AutoDL 通过完整分辨率标签控制横、竖、方形，不显示独立比例控件。

## 画布媒体产出模型

图片、视频、音频在生成成功并写入节点后，会冻结当时提交的产出模型。提示词面板里的模型下拉仍是下一次要用的选用模型，改下拉不会改掉已经生成的内容。画布外观中的「媒体信息」打开后，有内容的媒体节点在左下角显示产出模型；图片右下角继续显示尺寸和体积。上传、粘贴、截取、合并、提取音频和本地加工不记录产出模型。本次改动之前的节点不回填。分享页和版本预览画布不显示这块信息。

## 画布媒体版本

图片、视频、音频节点在原位重新生成或替换文件时，会把旧媒体保留为节点内的历史版本（V1、V2…，每个节点保留最近 30 个）。单张重新生成已有生成结果时直接在原节点产出新版本，节点 ID 和连线不变；多张输出、上传素材和「创建参数变体」仍新建节点。生成失败时旧版本保留在历史中，可以切回。

有可回看的版本时，节点右上角显示「V3/4」角标，浮动工具条出现「版本 N」按钮，右键菜单「版本历史」可用；只有一个版本时右键项置灰，工具条和角标不显示。版本面板底部的缩略图条支持悬停预览、方向键浏览、Enter 或双击切换；图片可开启「对比当前」，拖动分隔线比较。右侧显示模型、比例与分辨率、耗时、参考素材数量和提示词，并标出与当前版本不同的提示词。切换只替换媒体字段，提示词和下一次生成参数不变；锁定或生成中的节点不能切换。另可把任一版本另存为新节点，或删除非当前版本。

版本记录在画布文档的 `metadata.mediaVersions`，媒体字段沿用 `storageKey` / `content` 等原字段名，后端资源引用扫描和本地缓存清理都会把历史版本的资源视为在用。复制节点不带版本历史。只读分享页不提供版本入口。

## 画布资产视图

画布顶栏正中提供「画布 / 资产」切换（窄屏在画布菜单里切换），视图写在 URL 的 `?view=assets` 上，刷新后保持。资产视图把当前画布里有内容的节点整理成「类型 → 资产 → 版本」目录：类型固定为文本、Markdown、图片、视频、音频；上传的 `.md` 文本归入 Markdown。同一 `versionOfNodeId` 的 A/B 节点合并为一个资产，批量生成和拆层的子图归到批次下，节点内的 V1/V2 历史展开为版本，主版本带星标。

点选分类显示缩略图网格，点选资产或版本显示预览、尺寸、时长、模型和提示词，可重命名、下载、设为主版本或「在画布中定位」（切回画布并选中、聚焦该节点）。目录完全由画布节点派生，不新增数据表或接口；重命名和设为主版本走画布原有写路径。资产视图打开时画布快捷键暂停，左侧工作区轨道仍可用，原工作区的「资产」页签改名为「素材库」。实现见 `web/src/lib/canvas/canvas-asset-catalog.ts`、`web/src/components/canvas/canvas-asset-view.tsx`。

## 商品视频：元素替换

侧栏「商品视频」（`/product-video`）跟着「电商生图台」开关显示，对标电商 Agent 里的「商品视频 · 组合替换」：沿用一条参考视频的动作、运镜和节奏，换上自己的商品、模特和背景。

- 左栏放素材和参考视频。商品图最多 4 张，模特图、背景图各最多 3 张，可以本机上传、拖入或从素材库选；模特图还能从电商模特库选人脸或全身模特。放了哪一类就替换哪一类，没放的保持原视频不变，三类至少放一张。
- 参考视频可以上传、拖入，或粘贴抖音、TikTok 分享链接后「一键粘贴」「解析视频」（受「视频链接导入」开关控制）。「裁剪视频」可以选出其中 4–120 秒的一段，裁剪时预览只在选段内循环。成片时长跟随这一段。
- 生成设置：只列出能参考视频、单段至少能参考 8 秒的视频模型，参考图数超过模型上限的置灰。画幅有「跟随参考视频」时默认用它，否则选最接近参考视频的比例。清晰度跟随模型能力。声音有三种：保留原声（只换画面，成片换回原视频这一段的声音）、模型配音（模型支持时）、不要声音。可以写补充要求，可以勾选「先生成第一段预览」。
- 「难度与预期」按替换的元素、商品图张数、分段数和时长给出低、中、高三档，并列出最容易出问题的地方，例如只有一张商品图、Logo 小字、换人时的转头和口型、段间差异。这只是提示，不会拦截生成。做法参考 [video-element-replacement](https://github.com/yzsp-studio/video-element-replacement)：每张参考素材只绑定一个角色，原视频定动作、镜头、节奏和声音，商品图定商品，模特图定人物，背景图定环境；新主体按自然适配的方式套进原动作；单段可以定向重做；先做一段短预览。
- 底栏是「X 积分起」：按每段的生成时长分别向服务端报价再相加。还没切段时按选段长度均分估计段数。
- 生成时，服务端先按镜头切点把选段切成每段不超过模型参考时长（一般 15 秒）的参考片段。每段带着全部参考图和这一段参考视频交给视频模型，提示词用 @图片N、@视频1 绑定角色。各段最多 3 段并行，全部生成好后用时间线渲染按原顺序首尾相接，每段裁到参考片段的原长（生成得短时用最后一帧补齐），成片写入 AIGC 隐式标识。
- 右栏是「视频作品」，作品存在服务端。卡片上有成片、「组合替换」及替换了哪几类的标签、状态、时长、声音和预计积分。操作有编辑（把参数带回左栏，开始生成时新建一条，原作品保留）、再次生成（参考视频和选段没变时沿用切好的片段）、下载、删除（只删记录，素材保留）。生成中可以停止，未完成的可以接着生成，预览完成后点「继续生成」。展开分段能看每段的参考画面和生成结果，写下问题后「重做」这一段，成片会重新拼。
- 每一步的任务 ID 先写进作品再等结果。离开页面或刷新后会从作品记录接着跑，已提交的任务不会重复提交。

## 视频复刻：拆解

侧栏「视频复刻」（`/video-replication`）是独立页面，受后台「功能开放 → 视频复刻」控制（默认开放；关闭后侧栏不显示入口，页面提示暂未开放，已有记录保留，已经开始的拆解和分析照常完成），分首页和记录工作区两层，常见桌面尺寸（1280×800 起）下一屏放下、页面不滚动。首页是一行标题（含「复刻请用你有权使用的素材和形象」的提醒）、拆解分析 → 复刻方案 → 画布生成三步说明（和工作区的步骤条一致）、拆解入口和最近拆解：入口与创作页输入框同一套外观，粘贴链接时入口里列出支持的平台（抖音、TikTok、快手、哔哩哔哩、微博、小红书、YouTube，有解析接口的高亮带图标，没接入的置灰并提示可以下载后上传；管理员多一个「配置解析接口」直达后台），粘贴抖音、快手、小红书等平台的分享内容或链接（识别出平台会提示；后台没给这个平台配解析接口时，在同一位置说明暂时无法导入；后台关了「视频链接导入」时只剩上传），或点选、拖入本地视频（拖进来自动切到上传，上传前读出时长，超过后台设置的时长上限直接拦下，默认 3 分钟；链接导入时把这个上限交给服务端，超长的视频在导入时就失败，不先下载存成素材）；入口右上角写着当前的时长和镜头数上限。底栏选分析模型（能看图的文本模型；底栏不显示单价，打开选择器能看到各模型价格）、决定是否识别口播（后台关了口播识别、字幕转写未开放或服务器没配转写服务时，开关不能打开，下面写明原因），然后开始拆解，导入和上传的进度显示在入口下面。最近拆解默认排成一行，「展开全部」后是最近 50 次记录的卡片，卡片上是均匀取自全片的四张关键帧（竖屏排成一行，横屏拼成四宫格），角标是状态（拆解中、失败、未分析；分析过的写走到了哪一步：「有复刻方案」或「已建 N 块画布」）和时长。拆解任务一建好就进入这条记录的工作区（地址带 `?id=`），步骤条显示获取视频、切镜、模型分析、保存四步的进度。拆解在后台继续，离开页面不会中断；刷新或关掉页面后再打开，会接着分析没完成的那条，已经提交的模型请求直接取结果，不重复计费。服务端先用 ffmpeg 切镜（镜头数上限默认 60，后台可调低）、截关键帧、拼宫格，后台允许且有转写方式（后台选的转写模型，或服务器自建的 whisper.cpp 服务）时识别口播，这一步不收用户的模型费用。随后所选模型逐镜补全画面描述、景别、运镜、画面文字、制作方式和可直接复用的提示词，按所选模型计费。参考 [daihuo-fanpai](https://github.com/wangcanyu/daihuo-fanpai) 的做法，每镜还记下商品怎么出现、商品角色（没有商品 / 商品出镜 / 商品质感特写 / 包装文字要清楚，复刻时据此决定重做方式）和关键颜色，动作写过程而不是只写结果，并原样写进首帧和视频提示词；全片总结记下原片卖的是什么。回复缺镜头或格式不对时重试一次，再失败就报错，不拿空行补齐。模型听不到声音，没有转写时口播只从画面字幕读取。

记录工作区分三步：拆解分析 → 复刻方案 → 画布生成。标题一行下面是三步的步骤条，每一步写着现在的进度（几个镜头、是否已分析；方案里的商品、保留几镜、换商品几镜；建过几块画布），点哪一步切到哪一步，还没分析时后两步不能点，地址上分别是 `?id=`、`&view=plan`、`&view=canvas`。拆解分析这一步右上角是「重新分析」（在浮层里换模型）、「下载报告」（Markdown）和「下一步：复刻方案」。下面是镜头时间线：每个镜头按真实时长铺开，上方是模型给的节拍，下方是时间刻度，播放头跟着原视频走，点镜头从这一镜开始播放。再往下左栏是原视频（按剩余高度和画幅缩放）和时长、镜头数、平均每镜、画幅，右栏在「逐镜分镜」和「全片结构」之间切换；宽屏下页面本身不滚动，只有右栏面板里滚动，超过 120 字的提示词默认收成三行，可展开。逐镜分镜在一张面板里按镜头排开：关键帧、原片时间精确到 0.1 秒、景别与运镜、制作方式、画面描述、镜头设计、口播及来源、画面文字、商品与关键颜色、光影情绪、首帧与视频提示词（可一键复制）；左栏原视频下面说明口播从哪来，没识别口播时只在这里说一次原因；正在播放的镜头整行提亮，滚进分镜列表在看时，列表跟着播放进度走。全片结构是原片商品、开头钩子、节拍（点缩略图从那一镜播放）、为什么能吸引人、复刻建议、声音与花字。拆解结果和模型分析都存在服务端，刷新或换设备都能回看；镜头已切好但没分析完的记录，在时间线上方直接选模型「开始分析」。复刻方案整页滚动，左侧小节导航吸顶，三节：①商品档案：商品名称、外观、卖点（一行一条）、目标人群，最多 4 张商品实拍图（每张 20 MB 以内，必须传到服务器才算数）；②改写脚本：选一个文本模型，一次出 2–4 个切入角度不同的版本，保留原片的镜头数、节拍和每镜时长，只改口播和画面字，每镜口播按每秒 5 个字限长，只用档案里写的卖点、不编功效和绝对化用语，按所选模型计费；挑一个「用这个版本」写进逐镜；③逐镜计划：每镜左边是原片关键帧、时间、画面、原口播和原片商品，右边选怎么做（按描述重做 / 换成我的商品 / 沿用原片画面 / 不要这一镜），直接改口播（显示字数和上限，超了变红）、画面字、首帧和视频提示词，可以一键改回原样；「沿用原片画面」要先勾选「这是我自己的视频，或者我已获得原作者授权」，勾选后换商品的镜头保持原片构图；最下面是「下一步：画布生成」。画布生成这一步显示保留几镜、成片大约多长、换商品、按描述重做和沿用原片各几镜，以及问题（全部跳过、没授权就沿用原片会挡住；换商品却没有商品图、没写商品会提示），然后「创建画布并打开」；每次创建都是一块新画布，记进方案，下面「建过的画布」列出标题、时间和镜头数，可以直接打开。方案改动 0.8 秒后自动保存到服务端，保存失败照实提示并可重新保存。画布里放原视频、关键帧小图、复刻分镜（分镜脚本节点，首帧模式，口播、画面字和提示词用方案里改过的，跳过的镜头不进分镜）、商品图和拆解报告；换商品且有商品图的镜头多一个「镜头 N · 首帧（换商品）」图片节点，商品图（已授权时还有原片关键帧）只连到这个首帧节点，生成视频时只带首帧，不把商品图当视频参考；没有商品图时只把商品名称和外观写进提示词。以前的拆解分镜表不再显示「批量换装 / 创意生图」类型，主按钮是「创建视频脚本」。画布按原视频居中打开，复刻分镜在它右边。关键帧和宫格是拆解结果引用的资源，拆解 24 小时后也不会被游离资源清理删掉。用户侧暂不能删除拆解记录（管理员可以在后台删）；配音、字幕、在复刻页里直接拼片导出和剪辑工作台衔接尚未实现。接口见 [HTTP API](/docs/backend/http-api)。

## 视频复刻管理（后台）

后台「创作与扩展 → 视频复刻」（`/admin/video-replication`）一页管视频复刻的全部后台功能，分四个页签，当前页签和打开的记录记在地址里（`?tab=`、`?record=`）：

- **概览**：视频复刻、视频链接导入两个开关和口播识别的现状（点开去设置）；拆解次数（今天、近 7 天）、拆解成功率、存过分析的拆解数、用过的人数、链接导入次数与成功率、正常的解析接口数和覆盖的平台；近 14 天每天的拆解和链接导入数量（按 UTC 自然日，折线是其中失败的）；各平台的链接导入次数和成功率；最近 8 次失败的拆解和链接导入，失败原因不做用户侧改写，点拆解失败直接打开那条记录。
- **拆解记录**：所有用户的拆解记录，按状态和用户（用户名、昵称、邮箱）或完整任务 ID 筛选，分页。每行是第一镜关键帧、分析标题、时长画幅镜头数、用户、状态（失败带原因）、口播来源（没识别时在下面写原因）、分析模型和时间。点「查看」打开详情：原视频、基本信息、拆解提示、全片总结（含原片商品）和逐镜的关键帧、时间码、画面描述、口播与商品。已结束的记录可以删除（确认后删掉拆解结果、分析和这条拆解存的关键帧、宫格；被画布用到的图保留，原视频留在用户素材里），排队和拆解中的不能删。
- **解析接口**：链接导入用的第三方解析接口池（原「模型与渠道 → 视频解析接口」），功能见下一节。关了视频链接导入时顶部提示导入和巡检都已暂停。
- **设置**：视频复刻、视频链接导入两个开关（和「功能开放」是同一份配置，切换即保存）；拆解限制（视频最长 10–180 秒，默认 180；最多镜头 1–60，默认 60）；口播识别（是否允许；转写模型，可选系统渠道里协议为 OpenAI Audio 的音频模型，调 `/audio/transcriptions`，要能返回分句时间，比如 whisper-1，走平台渠道、费用由平台承担，不选时用服务器自建的 whisper.cpp 服务 `CANVAS_WHISPER_BASE_URL`；以及字幕转写开关、实际用的转写方式和选的模型现在能不能用）。限制和口播识别保存后，新建和排队中的拆解都按新设置执行；未保存的修改有提示，切换页签不丢。设置单独读取，概览统计读不出来时照样能改。

## 视频解析接口（后台）

用户粘贴的短视频链接（视频复刻、画布粘贴导入）不在服务器上跑下载器，而是交给管理员在后台「视频复刻 → 解析接口」（`/admin/video-replication?tab=parse`）里配置的第三方解析接口。支持抖音、TikTok、快手、小红书、哔哩哔哩、微博和 YouTube；哪个平台有开着的接口，前台就能导入哪个平台的链接，没有接口的平台直接提示「暂时无法导入」，画布里按普通文字粘贴。后台「功能开放 → 视频链接导入」（默认开放）关闭后，所有平台都不能导入，画布按普通文字粘贴，视频复刻只能上传文件，接口池的巡检、自动恢复和订阅同步也一并暂停（后台仍可编辑和手动测试接口），关闭前已经开始的导入会跑完。

- **按平台分类**：每条接口勾选能解析的平台。列表上方的平台标签带接口数，绿点表示这个平台现在能导入；顶部统计正常、自动停用、手动停用的接口数，可导入的平台和最近成功率。
- **多接口轮询**：有四种方式，分别是优先级（数字小的先试）、轮流（每次从下一条开始，均摊调用量）、按权重随机和最快优先（按平均耗时）。一次导入最多换几条可设（默认 3）。列表按导入时的尝试顺序排列，上方写明当前方式。
- **失败自动停用**：用户导入、后台测试和巡检的失败都计入，连续失败到次数（默认 3）自动停用，成功一次清零。冷却期满（默认 30 分钟）后台用测试链接自动重试，通过就恢复，列表里写着下次重试的时间；也可以手动「恢复使用」。某个平台的接口全被自动停用时，导入会挑最早停用的那条试探一次。视频超 3 分钟、超大小这类内容问题不算接口失败，也不再换接口。
- **测试可用性**：单条测试、按平台批量测试，编辑中的接口也能在保存前「试一下」。结果写明失败在哪一步（请求、返回、取字段、视频地址），给出取到的视频地址、标题、时长和接口返回的开头；只读视频开头确认能打开，不下载整段。视频地址字段可以留空自动识别，测试后一键填入找到的路径。可选定期巡检，按间隔测试开着的接口。
- **自动采集接口**：添加订阅源（返回接口清单的地址），后台按间隔（默认 24 小时）自动拉取，也可以立即同步。按请求方式、地址和请求体去重，已有的只更新定义；新接口先停用，打开「测试通过后启用」时用各平台测试链接测过再打开。
- **其他**：GET / POST 请求，JSON 或表单请求体，自定义请求头，密钥加密保存且不回显（用 `{key}` 引用，接口回显的密钥在记录里换成 `***`）；成功标记、错误信息、视频地址、标题、封面、视频 ID、时长的字段路径；下载视频时附带的请求头；复制接口、导入导出（导出不含密钥，可直接当订阅内容）；最近 100 条调用记录，可按来源和结果筛选。

接口池的数据存在 `system_settings`，不改数据库结构；接口定义见 [HTTP API](/docs/backend/http-api) 的「视频解析接口池」。

## 画布 Agent 名称、文案与形象

「站点及外观 → 画布配置」提供独立助手名称、入口文字、面板标题和欢迎/输入文案。助手名称同步用于界面和后续对话的自我介绍；名称只是数据，不改变工具权限，历史消息保留原文。支持导入授权的 Live2D Cubism 3/4 运行时 ZIP，预览后保存启用、调整高度、切回默认动态球。加载失败保留可点击的默认入口，上传和资源访问具有管理员校验和引用保护。Cubism Core 由部署者提供，真实播放待验收；不含图片自动建模。详见 [画布 Agent 外观与 Live2D](/docs/backend/canvas-agent-appearance)。

### 智能体形象（宠物皮肤）

后台「系统设置 → 智能体样式」管理用户可更换的助手形象，兼容 Codex 宠物图集（v1 九个动作；v2 另带 16 个视线方向）。内置 74 个可商用原创形象（猫狗、企鹅、龙、机器人、小精灵等，各有专属说话风格和台词），也可一次拖入多个 Codex 宠物 ZIP 或 WebP / PNG 图集批量导入；所有图集存在本服务器，运行时不访问外部站点。每个形象可设置上架、名称简介、分类、角标（如“新品”）、开放方式（免费、VIP 专享给所选分组、积分购买、累计消费满门槛免费领取；后两种可让所选分组免费）、限时促销（积分购买的形象按促销价或限时免费，可设开始和结束时间）、像素清晰、排序和“助手状态 → 动作”映射，上传的形象还能设置说话风格和专属台词；抽屉内可逐个预览动作和视线跟随。列表顶部统计上架数、付费形象、进行中的促销和累计收入，可按名称、分类、开放方式、上架状态、促销状态和来源筛选；列表分页（默认每页 50 个）；勾选多个形象后可批量上架 / 下架、设分类、设角标、统一定价与开放方式、按折扣开促销、结束促销、移到最前 / 最后和删除（内置形象与已有人拥有的形象自动跳过并说明原因）。导入的图集不占导入管理员的账号文件容量。「分类管理」可以整体改名（同名即合并）或移除分类。

用户在 Agent 设置「助手形象」或右键菜单的「形象商店」里按分类和获取方式（可使用、限时活动、免费、积分购买、消费解锁、会员专享）浏览形象，也可以按名称、简介或分类搜索；列表静止时只加载每个形象的一帧缩略图，悬停或选中才下载整张图集。卡片按说话风格配色，标出风格、角标和获取方式，价格醒目显示，促销时并列原价、折扣、活动名称和倒计时；顶部横幅汇总进行中的限时活动；悬停或点一下形象会挥手说一句台词。购买用积分一次性扣费，重复点击不重复扣费，下架后已拥有的形象仍可使用；积分明细显示为“购买形象”，促销时注明活动。限时免费的形象一键领取。消费解锁的形象显示累计消费进度和差额，累计消费（已结算的模型调用，购买形象不计入）达到门槛后第一次使用即领取，之后调高门槛也不收回。选择保存在服务端、只对自己生效。

右键点形象（或聚焦后按菜单键）打开形象菜单：顶部是当前形象的名片（动起来的形象、说话风格和一句台词），下面是打开助手、说句话、换形象（缩略图格子，形象多时可搜索）、形象商店四个快捷块，大小分段（小 / 中 / 大 / 特大 / 自动，保存在本机，选定档位后离开画布也按所选大小显示）、头顶气泡开关和收起 / 展开。画布入口按助手状态播放对应动作，完成时跳跃一次，悬停挥手，拖动时按方向奔跑；v2 形象待机时看向鼠标，鼠标停下 2.5 秒后回到待机。面板打开、页面隐藏或系统开启减少动效时停在第一帧。接口见 [HTTP API](/docs/backend/http-api)，数据表见 [后端数据库](/docs/backend/backend-database)。

使用宠物形象时，入口不再显示状态圆点、入口文字和待审批角标，改由头顶的云朵对话框说话：打开页面后按时段问候一次，之后每隔 4–7 分钟随机提醒时间、未完成的短剧或仍在运行的生成任务、上次的画布，或者给出创作灵感和贴心话；运行开始、完成、失败时各说一句，待审批时一直提示直到处理。台词按形象的说话风格（温柔、猫系、狗系、机器人、魔法、元气）和专属台词组合。气泡跟随形象位置，长句自动换行，始终留在视口内且不遮挡形象，头顶放不下时移到形象侧边；点击气泡收起，在「助手形象」里可以关闭闲聊（待审批提醒不受影响）。

## 素材库分类与画布媒体链路

## 大规模画布保存

单次变更多于 500 条 operations 时，客户端按原顺序分批提交，并在每批发出前保存可恢复的请求。全部批次确认后才完成整份画布保存；中途失败保留未确认内容和未提交操作，响应丢失则用原请求 ID 与正文重放。每批是独立事务，部分批次成功不等于整份画布已经保存。协议边界见 [HTTP API](/docs/backend/http-api)。

## 云端 Agent（写入与生成仍待真实环境验收）

浮窗支持移动、调整大小和浏览器偏好恢复；在画布里可以停靠到右侧，画布让出相同宽度不被遮挡，停靠宽度可拖动左边缘调整（视口窄于 960px 时自动回到浮窗）。面板使用实色背景，不做毛玻璃。后端支持逐轮对话、可信历史、取消、Skills 快照、画布摘要/精读、审批后的画布写入及媒体生成。运行中按 Enter 把消息排进本机队列（每个对话最多 5 条，只存在当前设备、按账号隔离），本轮正常结束后按顺序作为新一轮自动发送；按 ⌘/Ctrl+Enter 或在队列里点「插话」则插进当前轮（下一步生效，不打断正在飞的调用），未送达或撤回的插话可回到队列。本轮被停止、失败、被拒绝、Agent 提问或页面刷新后队列暂停，点「继续发送」恢复；输入框里连按两次 Esc 停止本轮。在画布里，往输入框粘贴、拖入或用「+」上传的图片（每条最多 9 张，PNG / JPG / WebP / GIF）先放到画布上成为图片节点，再以节点引用随消息发出，Agent 能看图也能拿它当生成参考；上传中、失败或只存在本机的图片不能发送，失败的可重试；也能从素材库选择、引用选中节点；粘贴超过 2000 字的文字时可转成画布文本节点再引用。输入框上方显示选中节点（单条可不带）、当前模型不能看图的提示和长文本转换，超过 16,000 字时显示字数并禁止发送。头部只常显停靠、历史、新建、更多、收起，设置、恢复大小、导出调试记录和快捷键说明收进「更多」；消息可复制，失败的一轮可「重试本轮」（会重新计费），离开底部时有「回到底部」；`Ctrl / Cmd + J` 在任何页面打开 Agent；多步任务可用 `plan_update` 维护待办清单并在输入框上方展示，未完成项会催办；`request_approval` 下首次 ≥2 项清单会先确认，`auto` 直接建立。`ask_user` 在输入框上方显示可点击的选项卡片并结束本轮；Agent 回复末尾列出的编号选项也会变成卡片，点一下就作为回复发送，不用再手动输入编号。每个用户有一份长期记忆文件（关于用户 / 工作笔记，默认 5000 字）：Agent 在用户纠正它、说明偏好或要求记住时用 `memory_update` 自己整理，默认立即生效，每次修改都能在聊天卡片或「Agent 设置 → 个人记忆」里撤销，也可以改成需确认或关闭。记忆快照只作为本轮的数据消息注入，不进系统提示；管理员可按用户只读查看。只读模式不能写记忆。用户已安装的技能编成预算受限的目录（最多占输入预算 5%），Agent 开始任务前会自己对照目录找合适的技能，每个技能可设为“自动”或“仅手动”；已装技能都不适用时，Agent 会推荐技能市场里的技能，由用户点安装。技能库和 Agent 设置提供按行业安装推荐技能的入口。本 Fork 的面板不提供手动固定技能、`/` 点名技能、技能库弹窗和场景胶囊，请求不带 `pinnedSkillIds`，技能全部由 Agent 按目录自动匹配。终态旧轮次按其冻结合同保留为不可变历史，新消息使用当前合同创建新轮，不篡改父运行；旧合同下仍活动或待审批的运行不会被新版服务恢复执行。生成由预算和独立审批控制，画布写入使用内容快照哈希；未开放外部 MCP。系统行为策略以版本化资源发布，用户/项目/画布可编辑常驻偏好；偏好正文固定在运行快照并按层只读，不整段塞入 system prompt，也不能提权或跳过审批。节点创建、更新字段、摘要投影和连线限制来自服务端能力 registry；能力卡同时描述用途、适用场景、不适用场景、维护代价和可用动作，由 Agent 结合镜头数量、连续性、逐镜审查和交接需求自主选择，不强制所有任务使用分镜。分镜脚本支持结构化创建、分页读取及按真实行 ID 追加、修改和删除；普通文本和 Markdown 不会被宣称为具备镜头级维护能力的分镜表。图片、视频和音频节点可安全修改标题与下一版提示词草稿，既有媒体、已提交提示词和任务状态不会被草稿编辑覆盖；媒体模型按生成模式和真实参考节点从统一目录筛选。审批和执行记录明确展示目标节点、类型、修改字段、名称变化及连线两端，前端不再依靠内部 ID 猜测；这些预览不替代服务端归属、快照、Capability、锁、预算与调用哈希校验。真实模型计费与浏览器联调仍待验收。

云端画布 Agent 已分离行为策略、用户目标、参考事实和运行状态。续聊保留已送达插话，不再继承代码预设的创作自由；旧待办只作上下文，可移除取消项，催办不会强制工具调用或无限重复。提示词来源与发布约束见[画布 Agent 提示词与用户意图](/docs/backend/agent-prompt-policy)，真实模型行为仍待场景验收。

同账号设备可在同一画布接续同一段 Agent 对话，恢复完整轮次和事件，并同步运行进度及审批结果。未发送草稿、未确认提交和下一轮设置保留在本机；手动选择的旧历史不会被其他会话抢占。原有画布互斥及幂等提交保护保留，旧父轮不能另开分支。

图片生成审批支持连续切换宽高比、分辨率和质量，同一次点击产生的多个参数更新会累积；扩展参数中的旧规格不再覆盖当前选项，提交时使用最终展示的规格。

## 3D 预演台（持续完善，待用户验收）

预演台从画布镜头节点打开，统一提供摆场、姿态、动画、摄影机与时间轴。镜头焦段和画幅共同决定取景，机位视图显示安全框；画幅在视口工具条选择，支持自适应（跟随视口）、2.39:1、21:9、16:9、4:3、1:1、3:4、9:16。添加角色时，每种体型用标准人偶缩略图展示，按同一机位渲染，身高可直接比较。构图截图、白模视频、深度图与深度视频使用同一镜头摄影机输出。深度产物回写为独立画布节点，不自动作为普通图片参考提交给模型。

工作台内可下载当前模式的镜头截图、录制镜头画面，或通过浏览器共享选择器录制含面板与操作过程的窗口。实时镜头录制要求标签页保持可见。第二屏监看用独立窗口显示镜头画面，支持全屏；自动定位外接屏依赖浏览器授权，也可以手动拖动。工具条与帮助面板提供[预演台快捷键](/docs/canvas/canvas-shortcuts)。

画布 Agent 使用 `previs_scene_read` 读取摘要，使用 `previs_scene_create`、`previs_apply_patch` 经审批创建和修改场景。路径操作生成真实变换关键帧，设置路径替换对象原变换轨道，清除路径清空该轨道；焦段修改同步取景。`previs_preview` 仍依赖已打开的浏览器工作台执行，尚无完成回执。

演员使用本地打包的 CC0 光滑人体模型（Quaternius Universal Animation Library 的 Mannequin，许可见 `web/public/previs/LICENSE-mannequin.txt`），姿势与动作写在规范骨架上再重定向到蒙皮，存档与模型无关。落地规则在前端提交与 Agent 写入两侧一致：演员和道具都可抬高（演员 Y 为脚底离地高度，可站上桌面、台阶），但不得低于地面，几何体按底面计算；打开旧场景时自动拉回地下对象并提示。检查器按变换、体型、外观、姿态、动作分组，道具库为按比例缩略图卡片并可折叠。程序化布景、排戏和离线逐帧编码仍属后续工作。

## 技能库个人分类与画布 Agent 筛选

技能库保留原有头部和技能广场共享分类；在“我的技能 / 我创建的”视图增加左侧个人技能库分类及技能数量。用户可为已加入或自建技能创建、分配个人分类；管理员也可创建对所有用户可见、可选、可用于筛选的分类。个人分类仅影响当前用户的技能库和画布 Agent，不改动技能广场共享分类。删除分类只解除相关归类，技能仍保留。画布 Agent 的“我的技能 / 已启用”列表可按个人或平台技能库分类快速筛选，市场页仍按共享分类浏览。

## 画布 operations 同步与本地恢复

画布内容按字段和对象生成 operations，节点、连线和顶层业务字段分别提交；平移、缩放等 viewport 只保存在本地。每次请求携带唯一 `mutationId` 和可选基线版本，服务端在同一事务中校验对象存在性、字段基线、资源归属并保存回执。可选顶层字段不存在时用 JSON `null` 表示，避免 `undefined` 被序列化为缺失属性。相同请求安全重放，响应丢失、断网、刷新或服务端暂时不可用时，浏览器保留已确认基线与未确认请求，后台使用原 ID 和原 payload 自动继续处理。结构化配额只聚合当前用户素材与画布数据，不扫描任务和 API 日志大字段，容量上限与事务语义不变。

不同字段的并发修改可以合并；同一字段或同一对象的基线不一致会返回冲突，当前本地修改继续保留。删除后的迟到节点、连线或媒体更新不会重新创建对象，只有显式新增 operation 可以创建实体。界面只显示同步状态，不提供版本记录、加载云端版、覆盖云端或手动恢复入口。

此合同不提供多人实时协同；它保证局部变更、幂等重放和删除保护，避免旧缓存静默覆盖新内容。内部历史表仍用于资源完整性维护和审计，不作为用户编辑入口。

相关实现见后端 [画布 operations 同步](/docs/backend/canvas-operations-sync)、`web/src/services/user-data-sync.ts`、`web/src/services/api/user-data.ts` 和 `web/src/pages/canvas/canvas-sync-status.tsx`。

## 画布智能引用

节点提示词面板提供“智能引用”入口，支持 AutoLink 开关和“一键引用全文”。输入已连接素材的名称、标签或素材栏序号后，按 Tab 或点击光标旁的候选项插入引用；全文引用会批量转换匹配到的指代，没有可转换内容时按钮禁用。

匹配仅覆盖当前已连接且激活的画布素材，跳过技能、素材库条目、重名歧义和已有引用。支持 `图1`、`图片1`、`image1`、`image 1` 及独立序号；普通数字文本如“约2秒”保持原样。AutoLink 默认在节点面板开启，开关为面板临时状态。

## 室内设计

左侧导航「室内设计」（`/interior`）用房间照片、毛坯照片、线稿或白模截图生成装修效果图，受后台「功能开放 → 室内设计」控制，默认关闭。

- **两种交互模式**：「快速出图」给业主用，只选出图方式、空间、风格和张数，模型用管理员配置的默认模型；「专业模式」给设计师和装企用，额外开放出图模型、画面比例、画质和全部参数。后台可以固定一种模式。
- **出图方式**：风格改造（只换软装 / 软装+硬装 / 全部重做）、毛坯出图（按预算档）、参考图迁移（照着喜欢的案例装自家房间）、线稿/白模渲染、虚拟布置（自住 / 出租 / 民宿 / 售房展示）和文字微调。内置 24 个风格、23 个空间。
- **风格对比**：一次最多选 4 个风格（后台可调），每个风格单独出图，结果按风格分组排在同一轮里，可以和原图切换对比。
- **3D 模型**：页面右上角在「效果图」和「3D 模型」之间切换。3D 模型选单个房间、整套户型或建筑外观，写一句描述（可附户型图或现场照片，需要能看图的模型），可选空间和风格，由所选文本模型写出设计方案（楼层、房间、门窗、楼梯、阳台、家具、屋顶、庭院和配色），再由程序按真实尺寸生成三维场景：墙体自动连接、不重叠闪烁，门窗带框和玻璃，退台变露台加栏杆，30 多种家具按尺寸拼成，地板、瓷砖、屋瓦有纹理。在页面里拖动旋转、滚轮缩放、右键平移，可切俯视、全屏、「剖切」看某一层室内、按楼层或分组隐藏、显示房间标注，下载 GLB（Blender、SketchUp 等能打开）或场景 JSON。一个模型一般二三十秒，离开页面不中断。搭好后可以一句话「改一版」（模型改方案，程序重新生成），每一版都保留。场景存成 JSON 资源，项目里只记资源 ID，和效果图共用项目；一个项目最多 30 个 3D 模型。范围默认「AI 判断」：只传一张图或写一句话，AI 先查室内设计知识库（尺寸规范、家具尺寸、动线、风格配色、建模要点；内置一套，后台可以修改、停用和新增）做方案分析，补全范围、空间、风格和各空间的尺寸布局，再据此建模，页面上显示参考了哪些知识。效果图和 3D 模型互相联动：效果图上点「用这张生成 3D 模型」带着图、空间和风格去建模；3D 模型上点「出效果图」按当前视角截图，转到「线稿/白模渲染」出写实效果图。这是示意模型，用来看布局和体量，不是施工图；按所选文本模型计费。
- **继续改**：任意一张效果图可以「用这张继续改」，自动切到文字微调，写一句话改局部，例如换沙发颜色、换地板。
- **对比与复用**：大图默认左右拖动对比原图和效果图。每一轮可以「用这一轮的设置再来一次」或下载整轮图片，失败的风格可以单独重试；回填后要用户确认再生成。页面上按 Ctrl+V 可以直接粘贴图片。
- **项目**：出图记录按项目保存在服务端，分「我的房子」和「客户方案」两类，可新建、重命名、删除；删除只删记录，图片保留在资产里。离开页面不取消生成，回来后接着显示结果。
- **后台**：「室内设计 → 室内设计管理」有概览（近 30 天出图次数、成功率、出过图的人、项目数，没设默认模型时提醒，近 14 天趋势，各出图方式、热门风格、空间和用到的模型，最近失败）和出图记录（所有用户的每一次出图，按出图方式、状态和用户筛选，点开看原图、效果图、参考图、参数和服务端拼好的完整提示词）；配置页签管理出图方式（输入、参数、提示词模板、默认模型和可选模型）、风格、空间和全局设置。模板和片段在服务端拼接，前台页面拿不到；拼好的完整提示词会记在用户自己的任务里。

接口、提示词变量和数据表见 [室内设计效果图](/docs/backend/interior-design)。

## 电商生图台

左侧导航「电商生图台」（`/studio`）是独立于电商 Agent 的商品出图页面，受后台「功能开放 → 电商生图台」控制，默认关闭。当前商品写在地址 `?product=` 里，刷新和回退都能回到原处。

- **生图表单**：商品图必填，出图以它为准；参考图可选，勾选「一键同款参考图版式」时照着第一张参考图的构图、文字位置和配色出图。表单包括品牌、商品类型、核心标题、卖点与商品信息（每行一条）、出图类型、视觉方向、市场、图上文字的语言、拍摄方式、目标人群、价格定位、补充要求、数量、清晰度、质量和比例。
- **出图类型可以多选**：单张类型（商品主图、白底图、场景图、卖点图、细节特写、模特图、多角度图、海报头图、种草图、随手拍、对比图、使用步骤、搭配图、平铺图、活动海报、尺寸图、参数图、包装配件）排成按钮，可以同时选几种，一次全部出完，这时「数量」变成「每种数量」，按钮写明几种共几张，生成记录里这一组的标题列出包含的类型。成套出图（5 张主图套图、10 屏详情页、模板套图）只能单选，选了套图就不再同时出单张类型；单张类型至少留一种。种草图是小红书式的生活分享画面；随手拍是手机随手拍质感的生活照，不冒充买家评价；活动海报不写价格；尺寸图、参数图、包装配件只写已确认的数值和配件。
- **商品图的视角与星标**：每张商品图的缩略图上标着视角（正面、侧面、吊牌等，识别时按它理解附图），点一下可改；左上角星标表示「外观依据」，出图只以点亮星标的图为商品外观依据。改成吊牌会自动取消星标；一张星标都没有时不能生成。
- **模板套图与镜头清单**：出图类型选「模板套图」后，从后台启用的模板或内置 1173 套模板库（按商品类型预搜索）挑一套。选择弹窗左侧按一级类目浏览（每类带当前搜索下的套数），中间是列表，右侧预览整套的视觉规范和逐张职责、画幅与「不放字」，确认后点「使用这套」。每张图按模板的标题和职责出，职责在提示词里优先于内置镜头规格，整套视觉规范代替风格锁，模板写了画幅和「不放文字」时照办；选中时存下模板快照，之后后台改模板不影响已选的这一套。主图套图、详情页和模板套图都显示镜头清单，可以勾掉这次不出的、上下调整顺序，导出长图与切片也按这个顺序。
- **出图策划（详情页、主图套图、单张图）**：除了模板套图，每种出图类型都能先让 AI 按这件商品策划。详情页固定 10 屏、主图套图 5 张，策划前不能生成（没有可用的文本模型时按品类默认的清单出）；单张图可以直接出，也可以先策划，策划按选中的类型和每种数量逐张排（模型写错类型时按位置改回），改了类型或数量后旧策划不再使用、按类型直接出。主图套图的第一张是搜索列表里的首图（白底图或卖点主图，按平台首图规则），其余每张一个点击理由，模型没把首图排在第一张时会挪上来；能排的有白底、卖点、场景、细节、多角度（要有侧面或背面图）、平铺、上身效果、对比、尺寸（要有已确认的尺寸）和种草。三种策划分别存在 `brief.detailPlan`、`brief.mainPlan`、`brief.singlePlan`（单张图另存当时的选择），切换出图类型时各自保留。后端按策划范围取知识库的创作类型规则（详情页逐屏连贯叙事、电商主副图层级、单图独立叙事）。
- **参考同类爆款与参考图**：策划时服务端从内置 1173 套爆款套图库（每套都是从一组爆款详情页长图反推出来的视觉语法和逐屏结构，原品牌、原文案和参数已去掉）里按商品类型和名称挑最相关的 3 套，把它们的色板、背景体系、字体、图标、版面规则和逐屏意图与文字区写给策划，要求学它们为什么能卖、不照抄；同类不够 3 套时从同大类补（同类一套都没有时补 2 套），每套标「同类」或「同大类」，同大类的只学版式和视觉体系；同类按类目关键词、类目名和品类中心词（如「儿童眼镜」的「眼镜」）对，商品档案没归大类时按「儿童」「宝宝」这类人群词推断。卖家在「参考图」里上传的大牌或爆款截图（最多 2 张）也随策划任务一起发给能看图的文本模型，策划先看懂它的版式、字号层级、配色、图标和文案节奏再用到这组图里，商品、品牌、文字和参数不照搬。每次策划都要写一条从这件商品最独特的地方出发、贯穿整组的创意主线（`concept`）和借鉴了什么（`inspiration`），卡片上显示「创意主线」「借鉴」两行；创意主线写进每张图的整套视觉规范。详情页版式少于 6 种或相邻两屏版式相同时，策划后会提示。策划提示词另有【视觉节奏与创意】：详情页整套至少三种明显不同的背景处理、至少两屏强对比，同一个商品角度和景别最多两次，至少一屏微距、一屏人或手和商品互动、一屏创意静物，首屏和关键屏用一个创意手法（超大比例或微缩、悬浮、文字和商品穿插、色块切割、光影投射、道具隐喻、镜面倒影、俯拍平铺）；主色要撑得起整屏；信息少时不拿商品标识和型号凑屏；主标题不能只罗列外观。
- **设计调性与文案**：策划从 7 种设计调性里挑一个写进 `tone`：国际大牌极简、时尚大片、东方雅致、日系生活、科技发布、爆款转化、年轻活力，卡片标题写出所选调性；出图时每张策划过的图多一层「设计调性」，写这种调性的版面、字体和摄影做法，主标题字重跟调性走，不再一律加粗。策划提示词里有【文案要求】：主标题讲买家得到的感受或结果，把卖点翻译成画面和感受，短句有节奏，不用「神器」「闭眼入」「yyds」「天花板」这类土味词和感叹号；读回时发现这类词会提示可以在补充调整里要求换掉。模型写字的图都带上防土味的禁止项（不用描边字、渐变字、发光字、贴纸、爆炸形和促销角标，整张最多两种字体），质感层要求商业大片级摄影。visual 和 style 里不写品牌名。
- **AI 分析并策划与补充调整**：表单顶部的「AI 分析商品」在可以策划的出图类型下变成「AI 分析并策划」，一步完成识别商品和策划（识别时已写的内容不覆盖，也不再弹替换确认）；模板套图下仍只识别。策划卡片里还没识别过商品时按钮也是「AI 分析并策划」，识别过是「AI 策划 N 屏/张」；文本模型明确不收图时跳过识别，直接按表单信息策划。卡片里有「补充调整」输入框（最多 300 字，写给 AI 策划，每次策划都会带上）；写了补充调整后按钮变成「按补充调整重新策划」，把上一版策划和意见一起交给模型，只改卖家不满意的地方；没写时重新策划要先确认会替换改过的内容。
- **详情页按商品策划**：详情页固定 10 屏，每一屏讲什么由策划按这件商品排，不再每件商品都是同一套。出图类型选「详情页」后，镜头清单先显示「先策划这 10 屏」，策划后才能生成：文本模型看商品图（模型收图时）和表单里的标题、卖点、已确认的事实，参考电商知识库里的详情页、版式、摄影、场景和文案方法，先分析买家下单前最关心和最担心什么，再正好排 10 屏（首屏和收尾固定，中间各屏的主题和顺序按分析定，屏型可以重复但内容和画面不重复），每屏写好目的、版式、具体画面（场景、摆放、角度、人物、道具、色调、光线、版式分区和文字位置）、信息元素和文案，再给一份整套设计规范和策划思路。版式有 10 种：海报大字、左右分栏、图标卖点、引线标注、对照、细节拼格、场景大片、大字数据、参数尺寸、收尾承诺；相邻两屏版式不同，整套至少 6 种，同一屏型不连续超过两屏。信息元素写几个图标各画什么、引线指向哪些部位、拼格每格放什么；要点在图标卖点、引线标注、拼格和收尾版式里就是图标、引线和格子的标签；主标题上方可以有英文栏目小标题（只收英文字母，不带序号；以前带「01」这类序号的策划和出图记录读回时去掉序号）。详情页是一张连续的长图，每屏不画页码、屏号和 01、02 这类序号，使用步骤屏的步骤编号除外。设计规范写色板（底色、主色、强调色）、背景体系、光线、字体与字号层级、栏目标题样式、图标样式和装饰元素。出图时版式和信息元素进「这一屏的画面」，图内文字允许图标、细线、引线、色块和信息卡这类设计元素，要求画面是排过版的详情页而不是一张商品照片加一行字。镜头清单的每一屏显示版式名，展开后可以改版式和信息元素。材质、参数、尺寸、包装要有已确认的事实，多角度要有侧面或背面的商品图，依据不够的屏型不排；文案里出现原文没有的数字会被去掉。依据不够的屏被去掉后不足 10 屏时会提示少了几屏，少于 6 屏要求重新策划。策划好的屏可以勾选、调顺序，点笔形按钮修改屏名、画面和文案；出图时按策划的画面和整套视觉规范出，不再套按品类固定的构图、光线和背景，生成记录里这一组叫「详情页 · 按商品策划」（主图套图和单张图同样带「按商品策划」）。可以重新策划。没有可用的文本模型时才按品类默认的清单出。策划和识别用同一个文本模型。
- **识别商品自动填写**：按钮旁边直接显示当前的识别模型，点开可以换一个能看图的文本模型；看商品图后自动填品牌、类型、标题和卖点，已经写了的字段不覆盖。识别走后台「商品档案」能力，分析时由服务端注入电商知识库里与这件商品相关的卖点、文案、平台规则和品类知识，这份知识库与电商 Agent 共用。
- **商品档案**：识别结果按分组列出，每条带证据等级。只有「图片可见」和「已确认」的信息进入出图提示词；推断的可一键确认，值可以单击修改（改过的记为卖家确认），也可以删除。识别时没能确认的问题可以直接回答，答案作为已确认的信息写进档案，或者忽略。重新识别时以新结果为准，卖家确认过的信息保留。
- **生成记录**：每点一次「生成商品图」记成一组，数量、比例和文案在提交时定下；最多保留 30 组，总占用过大时也从最旧的删起，进行中的不删。缩略图按成品的实际宽高显示。每张可以再出、采用、下载或加为参考图；大图查看完整显示整张图，支持切换和采用。大图的底色跟随主题（浅色为浅灰、深色为深灰）；点一下图片放大到原图像素，再点一下回到整张，滚轮或触控板捏合以指针处为中心缩放，放大后拖动查看各处，图片下方的缩放条可以放大、缩小和回到整张。详情页成组可导出长图与切片，长图屏与屏之间不留间隔。
- **模特设定**：出图类型里选了模特图（单选或和别的类型一起选）、拍法为「模特穿搭/使用」，或套图里有上身效果时，「出图类型」正下方出现「模特设定」，人脸、全身模特、姿势、模特样式（造型）四项排成两行两列，可以从模特库各选一个，也可以不指定；人脸和全身模特都决定「是谁」，只能二选一，选了一个就清掉另一个。同时出几种图时只用在模特图上，拍法选了「模特穿搭/使用」时每张都用。选人脸、全身模特或姿势时，原图会复制一份到自己的资源库，作为参考图跟商品图一起提交；提示词按图号说明长相（全身模特还包括身材比例，没选姿势时可以参考它的站姿）和姿势只作参考，不照搬它们的服装和背景，造型写成文字。模型能带的参考图不够时，商品图至少保留一张，放不下的模特参考改用文字描述。
- **电商模特库（后台）**：后台「创作与扩展 → 电商模特库」维护模特人脸、全身模特、姿势和模特样式。类型页签带各自条数；可以按分类（带条数）、上下架状态和关键词筛选，搜索停顿后才查；每页 48 条，可以全选本页，换筛选或翻页时清掉选择。未上架的卡片图片压暗。新增时可以一次选多张图，每张一条、名称取文件名；人脸和全身模特要勾选「已获得肖像使用授权」才能上架，全身模特和姿势要带图，模特样式要写造型描述。卡片上可以直接上下架、修改、删除，也能批量操作。
- **模特库远程拉取**：后台模特库页头的「远程拉取」可以一键拉取内置来源 ai-pose-gallery-zh（固定在一个提交上，只取全身标准系和半身可爱系姿势、正脸人像、去掉内衣睡衣与性感穿搭的服装，18+ 分组都不取，约 2451 条），也可以填一份素材清单地址。服务端在后台下载，弹窗显示进度和失败明细，可以停止；关掉弹窗也会继续，页头按钮显示「拉取中 x/y」，结束后列表自动刷新。每条走后台新增同一套校验、缩略图和审计，按类型 + 分类 + 名称跳过已有的，可以反复拉。没勾选肖像授权时人脸和全身模特先不上架。命令行 `backend/cmd/studio-models-import` 也能做同样的事：`-source` 直接拉取并导入，`-source … -export <目录>` 只下载图片并写清单（给连不上外网的服务器），`-manifest` 导入一份清单；人脸和全身模特默认不上架、不标授权，确认已取得授权时才加 `-face-consent-attested`。该图库的图片著作权归原作者、标注非商用，拉取前须取得授权。
- **电商生图台后台**：后台「电商生图台」分商品档案、出图策划、出图提示词、套图模板四个页签（出图策划和商品档案一样是开放开关加分析指令，能力编号仍是 `detail-plan`，默认指令覆盖详情页、主图套图和单张图），页签名后显示状态（已开启、已改几条、启用几套），有没保存修改的页签带圆点；页头是保存状态、载入上一版、刷新、撤销和保存修改。商品档案页是开放开关和分析指令（标出内置或自定义与字数）。套图模板的「后台精选」左边是列表，右边编辑名称、类目、用途、来源、整套视觉规范和每张图，每张可以上移、下移、移除，必填项为空时标红，移除整套要确认；EcomGen JSON 在弹窗里粘贴导入，解析失败在弹窗里说明原因；「内置模板库」加入精选前可以选用途。
- **出图提示词（后台）**：后台「电商生图台 → 出图提示词」按 23 种镜头（这张图做什么、构图、机位、光线、背景与道具、约束）、拍摄方式、市场、质感、品类规则和微调标签分组，显示内置写法，改过的成为覆盖，可以单条或整组恢复内置。左侧分组栏分主图镜头、详情页镜头和通用规则，滚动时吸顶；搜索时只留命中的条目。保存后生图台出图和「查看这张的提示词」都按新写法；商品事实、图上文字和平台硬性要求不在这里改。
- **质量与清晰度**：有独立分辨率参数或多档质量的模型照常选；GPT Image 这类质量只有 auto、按像素尺寸出图的模型，「质量」选的是尺寸预设的清晰度档位（1K / 2K / 4K）。GPT Image 2 这类同时有多档质量（自动 / 低 / 中 / 高）和多档尺寸的模型，同一格里并排两个下拉框「清晰度 · 质量」，清晰度默认 1K（模型没有 1K 时用模型默认档位），需要更清楚时选 2K、4K，提交时直接给这一档对应比例的具体尺寸；按参数声明的模型也按它声明接受的尺寸放开 2K、4K。质量只有 auto、靠尺寸档位分清晰度的模型（「质量」下拉框里是 1K / 2K / 4K），没选过时也默认 1K。「出图设置」旁边的「套图模板库」按钮直接打开模板选择。
- **比例**：除了自动和模型支持的比例，可以选「自定义」填宽和高（各 1–99，长边不超过短边的 3 倍，存之前约分）。模型允许自定义尺寸时按所选清晰度算出具体尺寸；不允许时落到最接近的预设比例，比例下方写明会按哪个比例和尺寸出。
- **质感**：15 种预设（雾感极简、暖调生活、高级暗调、清透自然、明亮活力、纯净高级白、日系原木、奶油治愈、科技冷感、新中式东方、轻奢金属、运动能量、童趣糖果、自然植萃、杂志大片），新商品默认「按商品推荐」：策划过的出图类型（详情页、主图套图、单张图）由策划按商品和人群挑一个，下方显示「策划挑了「…」」；没策划时按品类挑（服饰用杂志大片、3C 用科技冷感、母婴玩具用奶油治愈等）。后台「出图提示词」的质感分组同样列出全部预设。
- **调整这一张**：大图右侧可以给这张图加微调（更明亮、更暖、更清冷、商品再大一点、背景更干净、换个角度、更柔和、更有质感），在「还想怎么改（只改这一张）」里直接写修改要求（200 字内，例如换背景、挪商品、改标题颜色），改这张图上的标题和要点，然后按调整再出一张，之前的结果都保留。修改要求写进这张图提示词的「这一张的修改要求」层，和画面要求冲突时以它为准，商品外观仍以商品图为准。「查看这张的提示词」按提交时的规则现场编译，逐层标出来源和字数，可以复制。
- **保存**：编辑先写本地，再按商品整体保存到服务端；每个商品带服务端修订号，助手或另一个窗口先改了时取回最新版本，再把本地未保存的修改重新套上。删除商品只删档案与记录，照片和生成图仍在素材与任务里。
- **助手**：打开一个商品后，全局助手这一轮绑定该商品，能读状态、看照片、按证据等级写档案与卖点、排镜头；它只交来出图确认卡，用户确认后页面才提交任务并计费。内置技能「电商出图方法库」在这类对话里固定可读，不需要用户安装，镜头角色以它和工具声明为准；工具参数填了不在可选范围的值时，助手会收到这个字段的可选值。
- **助手的用量显示**：输入框正上方默认收起成一行（约 28px）：迷你进度条带压缩线、已用 / 窗口、百分比、阶段标签和本轮摘要（tokens、每秒 tokens、耗时、工具调用次数），放不下时摘要省略，整行点一下展开成用量卡片，卡片右上角可以收起，展开与否记在本机。用量卡片第一行是上下文占用（已用 / 窗口、百分比，接近或到达压缩线时标出阶段，轮次进行中标「进行中」），右侧是当前模型名和「明细」；第二行是占满宽度的进度条，竖线是自动压缩线（窗口的 80%），下方写剩余多少和到多少自动压缩；第三行是本轮五项：tokens 合计、缓存命中、每秒 tokens、耗时和工具调用次数，面板窄时排成三列。点「明细」展开上下文构成、模型调用次数、输入 / 输出 / 缓存读取、模型和工具耗时占比与工具种类，展开与否记在本机。还没有读数时卡片也在，显示模型名、上下文窗口、压缩线位置和「发出消息后开始统计」，本轮五项显示「—」；新一轮开始后先保留这个对话上一轮的读数并标「上一轮」，等这一轮的读数到了再换，换到新对话不会带着旧对话的读数。每轮最后一条回复下方显示模型名、生成速度与 token、回复时间、复制，正常结束的最新一轮可以直接重试。没有真实数据的项显示「—」或不显示，不编数字；工具单次耗时和对话分叉暂未提供。

## 批量创作表

批量创作表每行是一项任务，每个参考图格子绑定一张图片；同一行可通过多个参考图列使用多张图。点击格子可选择画布图片或上传，也可把图片连线接到指定格子。已有图片替换前确认，清除格子保留源图片节点；保留列排序和表内跨行、跨列交换。

左侧 1、2 等列端口直接生效：一张图片供该列各行共用，多张图片按连接顺序分配。单格更换或清空后成为独立配置，不被列变化覆盖；“按列填充”可在确认后恢复已连接列的统一配置。列同步只更新参考图，不重建任务行；AI 文本列表创建的表格保留独立行、动态文本列和原有生成流程，未开放普通文本节点直接连入批量表。

顶栏、普通表头、行号和非交互留白均可拖动整表；输入框、参考格、按钮、列排序和原生滚动条保留各自操作。表内支持文字拖选、内部滚动、底部添加和在指定行下方插入。放大编辑与行内编辑使用同一份提示词。全局提示词非空时统一覆盖各行的生效提示词，清空后恢复各行原文；界面显示实际生效来源，Agent 的 `set_global_prompt` 和 `generationPreview` 沿用此规则。“批量换装”和“创意生图”的预设保留。

任务入队时保存提示词与参考资源快照，排队期间修改或旋转源图不会改变已提交的输入；旧结果在输入变化后标记“输入已变更”，由用户决定是否重新生成。超过 20 行时仅挂载可见行、附近行及正在编辑的行，减少大表 DOM 和重绘开销。最终浏览器联调与性能验收见[待测试](/docs/progress/pending-test)。

## 图片尺寸与方向

图片节点按原图比例确定显示尺寸，可用角点调整大小或打开图片预览。普通滚轮保留原画布操作；单选一张未锁定的普通图片后，按住 Ctrl 滚轮可等比例改变其显示尺寸，鼠标移到画布空白处仍作用于选中图片。连续滚动合并为一次撤销和保存，不重采样图片或改变生成参数。编辑框、表格内部、多选、锁定、图层图片和只读页不进行这种尺寸调整；触控板捏合仍操作画布。

在原图工具中选择“向左转 90°”或“向右转 90°”，首次会保留原图、自动创建已经旋转的编辑副本，并连接和选中它。副本顶部保留左右转按钮，之后在同一副本上继续旋转或恢复创建时的方向；也可提前用“创建编辑副本”。

旋转生成实际图片资源，副本的下载和新提交引用使用校正后的方向；原图及其既有引用保持原样。引用编辑副本的格子会随副本更新，已入队任务仍使用提交时的快照。原方向与已生成方向保留，重复切换可复用资源。锁定、只读或尚在上传的图片不能旋转；此入口不提供任意角度或镜像操作。节点工具组菜单使用统一宽高限制，长说明单行显示并保留完整悬停说明。

工具栏根据侧栏以外的实际可用宽度收起次要操作；节点编辑面板根据剩余高度调整位置或内部滚动，避免遮住底部控件。未选择显示模式时，窄于 1024px 的窗口默认使用专注模式；用户明确进入或退出后，窗口变化与刷新保留该选择。

任务类型有三档：`try_on`（批量换装）、`creative`（创意生图）、`product`（电商创作）。`product` 面向电商物料产出：同一件商品的多视角实拍连到同一行作为参考，默认提示词先写商品锁定块（形状、颜色、材质、图案、结构、数量、标识文字不得改写），再写主图拍摄配方（构图、背景、布光、留白）。只有一张商品图也能直接生成；输出节点标题前缀为“商品”。

## 提示词放大编辑

图片和视频节点的提示词面板支持放大编辑：窗口默认约 `min(1200px, 92vw)`，编辑区最小高度 200px，右下角可对角拖拽，方向键可微调。切换节点后尺寸恢复默认，节点上的紧凑面板外观不变。

## 完整 AI 拆图工作流

图片节点的 AI 拆图可先用支持视觉输入的文本模型规划图层，再选择专用拆图模型，或用普通图片模型分别重建背景与前景。规划发送经过资源归属校验的实际像素；规划结果校验图层数量、区域与提示词，失败保留可修正的错误。

生成结果组成同尺寸图层组，支持展开、显隐、合成预览、复制、删除、失败重试和刷新恢复。前景可按需去背景，Image Tools 强制输出 PNG；透明内容可按有效区域裁切并另存为独立素材。派生图片使用独立资源与素材标识，避免覆盖原图或其他图层。

规划、生图及可选去背景沿用已有任务与计费；本地合成、显隐和素材裁切不调用生成模型。普通生图是语义重建，不能保证与原图逐像素一致。图层数、像素与输出比例受前端限制，供应商失败如实显示。

## 系统渠道排序与前台别名

系统渠道模型选择器直接读取渠道下的模型列表：一级跨渠道按“模型展示名”分组并显示原色 Logo，二级显示该模型的“渠道展示名”及规格售价；留空使用所属渠道名称。模型调用标识不必相同，也不反查逻辑模型。系统渠道的“前台名称”已移除。调用保留用户选中的具体渠道，收起后显示“模型 · 渠道”，不因另一渠道更便宜而自动切换。图标优先使用图标库的原色版本，缺少彩色版本时使用单色版本；缺少配置时显示通用图标，不猜测产品品牌。

渠道模型价格档支持管理员单独配置积分成本价；后台请求记录分列显示预授权、实收和成本金额，只有已结算订单才显示实收。成本按下单快照计算，不追随之后改价；普通用户页面及接口不返回成本字段。

系统渠道模型列表按规格显示成本价 / 销售价及利润率；文本输入、输出、缓存 Token 分开呈现。勾选多个模型可统一调价：弹窗一行一个模型，展示模型名、渠道展示名（上游 ID）、规格、成本与可编辑售价，多规格在模型行内纵向对齐。输入目标利润率并选择保留 0–6 位小数（默认 2 位），按 `成本 / (1 − 利润率)` 四舍五入实时计算；也可点击「重新计算」覆盖手动值，再逐项修改。保存最终输入售价，服务端校验价格与版本并原子保存，不改变成本或启停状态。

后台系统渠道通过“设置排序”、模型管理通过“自定义排序”打开完整列表。支持搜索选择条目后输入目标位置，也可拖动、上移和下移；列表显示从 1 开始的位置，点击“保存排序”统一生效，取消不会修改线上顺序。渠道行的“更多”菜单支持复制渠道，复制会生成独立的渠道、模型和价格档，并保留原连接配置与凭证。排序不受筛选及分页影响；并发修改会提示重新加载，避免覆盖其他管理员的调整。系统渠道模式下，用户端模型选择器沿用同一渠道及模型顺序。模型排序独立保存，不改变价格、能力版本或启用状态。

系统渠道可设置可选的前台别名；为空时显示渠道名，设置后公开目录和用户会话只返回别名，后台仍保留原名。别名最长 80 字，支持后台搜索。前台模型目录模式保留其独立配置。

注册默认每 IP 每小时允许 30 次注册请求、60 次验证码请求，单邮箱每小时另限 10 次且发送后间隔 60 秒。失败尝试也占请求额度，达到上限后的拒绝不会继续增加计数或延长窗口；限流响应携带真实剩余等待时间，注册页面显示倒计时并防止重复提交。已保存的运行策略仍需管理员按实际共用网络规模调整，不随默认值升级自动覆盖。

定时闲置资源清理与后台手动删除共同保护外观配置引用的浅色 Logo、深色 Logo、登录视频及封面；即使资源超过闲置期限也不会删除，外观配置无法读取时停止相关清理。

## 章节资产提取与任务浏览

画布视频支持鼠标悬停 350ms 后静音预览前 3 秒，不循环；全局仅一个悬停解码器，离开或操作画布立即停止并恢复封面。手动播放优先，系统开启减弱动态效果时不自动预览。

剧情章节支持一次提取角色、场景与道具，分别写入角色、环境和道具待确认资产。输出必须包含三类数组；无人章节可以只产生场景或道具，不把缺失字段当作提取成功。

场景和道具确认后保留描述与生图提示词，尚未出图时显示「待生成图片」。可使用项目画风生成参考图，或绑定素材库中已有图片；提取和确认不会自动发起收费生图。图片绑定创建新资产版本，已有镜头、画布继续引用原图片。生成任务的成功状态与图片绑定共同提交，取消或失去租约的任务不能换图；晚到图片不覆盖较新资产版本，原生成结果仍可在任务中心恢复使用。

任务详情只读取任务与日志，不因打开详情写入画布。视频任务列表和网格优先展示已有封面；没有封面时，在进入视口后提取首帧缩略图。后台请求明细默认仅显示请求，可切换仅下载或全部明细，导出沿用当前筛选条件。

## 站点及外观

管理员可以在“系统配置 → 站点及外观”统一管理品牌识别、登录页、SEO、首页收尾与备案、皮肤主题。品牌识别包括站点名、英文品牌标识、浅色与深色 Logo 和 Logo 外框；登录页包括主标题、说明、品牌视频和可选封面。Logo 可以只上传任意一套并自动复用，也可以分别适配浅色与深色界面；关闭外框后 Logo 会在原导航占位内等比放大。

前端入口在加载 React 应用之前先读取 `GET /api/public/appearance`。初始 HTML 不包含内置品牌名、Logo 或默认 favicon；只有公开配置成功或明确回退到内置外观后才渲染应用，避免自定义品牌访问时先闪现“影策”。自定义视频未设置封面时保持纯色背景直至视频首帧就绪，不复用内置视频封面。

浅色 Logo、深色 Logo、视频和封面通过后台专用上传接口进入现有资源存储，并由稳定的公开 slot URL 读取；公开响应不暴露资源 ID。正在使用的外观资源会阻止管理员从资源管理页直接删除。英文品牌标识可作为对象存储路径前缀建议，但不会自动覆盖已经保存的前缀或改写历史资源。“恢复影策默认”会恢复内置品牌值、SEO/页脚默认值、经典皮肤和默认 Logo 外框，同时保留已经上传的素材文件。

SEO 标题、描述、可选关键词会投影到浏览器 metadata、Open Graph、Twitter Card 与 canonical；版权信息在公共登录场景页脚显示。ICP备案默认关闭，启用后必须填写备案号，并链接至工信部备案系统。注册验证码与密码重置邮件的标题、正文和继承型发件人名称都会使用当前站点名。

皮肤主题以语义令牌集中管理浅色/深色背景、文字、表面、边界、主色、控件状态、hover/active/focus、图标、圆角、尺寸、动效和阴影。默认“经典黑白”不可修改或删除；“青瓷工作室”“暖柿纸境”“霓光紫境”作为重新校色的可编辑初始数据。每套主题还可独立设置警告色、危险操作常态/悬停/按下/前景，以及开关开/关轨道、悬停和滑块色。管理员可从经典或当前主题完整复制、新建、改名、编辑、启用和删除自定义主题；页面只消费语义变量，不按皮肤 ID 分叉业务组件。

主题卡顶部会按语义使用频次展示该主题浅色与深色令牌的全部去重颜色，宽度不足时保留高频色并截断尾部。颜色编辑器只在直接点击色块时打开系统取色器，点击名称、说明或 HEX 输入不会误触。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。

## 画布同步与离线恢复

画布编辑会先写入浏览器本地持久化，再由统一同步队列提交 operations。浏览器在线时自动保存；断网、响应丢失或服务端暂时不可用时，未确认请求会保留在本地 journal，恢复连接后按原 `mutationId` 和原操作内容自动重放。同步状态会区分保存中、已完成、待处理和错误，用户无需选择本地版或云端版，也无需手动强制覆盖。

## 画布外观

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

自定义主题会继承用户进入前的浅色或深色基础界面，并允许在“浅色界面”和“深色界面”之间切换。界面样式复用原项目整套节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色；切换界面样式不会覆盖已经选择的画布背景和网格颜色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

## 方舟素材库

所有素材组都建在平台配置的方舟账号下，分三类：

- **真人人像**：本人完成 H5 活体认证后建组，组内只能上传同一人的照片；有授权期限（默认 365 天），到期后不能上传或用于生成。
- **虚拟人像**：AI 生成或绘制的虚拟形象，直接建组。
- **版权 IP**：只能由管理员创建，授权给全部或指定用户使用。

**用户端**在「设置 → 方舟素材库」按类型管理素材组，不使用抽屉：真人建组按「填写姓名 → 扫码认证 → 上传照片」三步在页面内完成，二维码面板提供「在本机打开认证页」和「我已完成认证」；电脑端每 3 秒刷新认证结果，手机完成后跳到公开结果页 `/ark-portrait/result`。组内可直接上传图片或从素材库选图提交认证，开启审核时先由平台审核、通过后才提交方舟。认证通过的图片自动移入素材库「方舟认证」分类（带盾牌图标），卡片显示【方舟真人认证】等角标；素材档案里可查看认证类型、素材组、方舟素材 ID 与授权期限，未认证的图片可直接「提交认证」。授权给本人的平台素材需手动「加入素材库」，服务端复制成本人的资源。

**画布**：图片节点绑定的素材库图片已认证时，节点右上角显示【方舟真人认证】标识；用方舟视频模型生成时自动以方舟素材 ID（`asset://`）引用。节点换过图片后不再引用该 ID，标识也随之消失。

**管理端**「方舟素材库」分为三个视图：

- **素材组**：统计各类素材组与即将到期 / 已过期的真人组，按类型、归属、授权状态和关键词筛选；详情里修改名称、平台组授权用户和真人授权到期时间，向平台组上传图片（免审核），删除素材组或素材。可新建虚拟 / 版权 IP 素材组、登记控制台已有的素材组，或为平台真人素材组发起 H5 认证。
- **上传审核**：用户上传的图片逐条或批量通过（提交方舟）/ 驳回（填写原因）。
- **配置**：方舟站点、Region、ProjectName 与 IAM 凭据；可信素材自动同步；开放真人 / 虚拟素材组、每人上限、真人授权有效期、上传审核；按组收费及真人 / 虚拟价格。

收费按组一次性扣除平台积分：真人在发起认证时冻结、认证成功后扣除，失败、过期或取消自动退回；虚拟在创建成功后扣除。平台积分关闭或平台素材组不收费，删除素材组不退款，流水显示在积分中心。原有的 Seedance 可信素材自动同步保持不变。接口见 [HTTP API 合同](/docs/backend/http-api)。

## 剪辑成片（时间线编辑器）

“剪辑成片”是项目详情里的时间线编辑器入口（`/projects/:id/editor`），用于把已就绪的分镜视频编排成一段可播放、可导出的成片。它运行在浏览器本地时间线模型之上，通过后端任务队列完成语音转写与成片导出，编辑器本身不直接触碰原始媒体大文件。

### 使用入口

- 项目详情“制作流程 → 剪辑成片”步骤卡，或地址栏直接访问 `/projects/:id/editor`。
- 编辑器按项目隔离时间线状态；离开后再次进入会恢复该项目的编辑器快照。

### 当前能力

- **轨道与命令**：时间线支持添加、删除、拆分、移动、修剪片段等操作，全部通过统一命令状态机执行并进入 200 层历史记录，可撤销与重做；非法操作整批拒绝，不产生半应用状态。
- **预设面板**：左侧“添加”分类提供 8 个内置片段/字幕插件，按分类分组接入同一插槽注册链，第三方插件可与内置面板共存。
- **权限与执行边界**：命令执行遵循失败关闭（fail-closed）策略，`timeline.command` 权限与全局 `plugins.run` 权限分开控制；未授权插件或命令不会被执行或回显。
- **语音转写（字幕）**：对时间线音视频发起转写任务，转写进度沿任务 SSE 回流，完成后生成字幕轨。
- **成片导出（渲染）**：发起渲染任务，由服务端 ffmpeg 按渲染计划输出成片；渲染成功后在项目概览的“剪辑成片”步骤卡呈现“已输出 N 个成片”，并作为该步骤完成度的判定依据。
- **AI 编辑助手**：可以用自然语言描述剪辑意图，系统将其解析为受支持的命令序列；不超过 3 条命令时直接执行，多于 3 条先给出差异预览，确认后才批量执行。

### 运行环境要求

- 语音转写依赖本地 whisper.cpp 服务（`CANVAS_WHISPER_BASE_URL`），未配置时转写任务明确失败。
- 成片导出依赖服务端 ffmpeg（`CANVAS_FFMPEG_PATH`，留空时在 PATH 中查找）。
- AI 编辑助手需要可用的文本模型渠道。

画布支持风格、运镜、九宫格提示词工具及自定义特效工具，提供收藏和私有自定义工具。工具仅加入提示词或创建待生成子节点，选择工具不自动发起生成。画布左侧提供主页、折叠、节点、资产、任务和历史菜单，不再提供独立工具菜单，展开面板沿用主分支主题。资产支持分类、搜索、分页和直接插入，复用现有素材服务及插入合同；任务和历史独立，历史明确展示最近 30 条。图片节点直接展示风格和预设，不再展示提示词模板入口；其他节点的提示词模板保持不变。

## 后台技能管理

后台「创作与扩展 → 技能管理」列出全站技能，包括私有和已下架的技能，可按名称、作者、ID 或仓库搜索，按上架状态、来源和分类筛选。管理员可以：

- 编辑所有技能的基本信息（名称、简介、分类、来源地址、展示媒体、补充信息），使用与用户端相同的技能信息表单；公开状态由作者决定，后台不改。
- 在与用户端相同的技能工作台里编辑所有非 GitHub 技能的文件内容；GitHub 技能只能浏览文件。
- 下架 / 上架技能。下架后技能从技能广场、用户技能库、Agent 目录中隐藏，作者也看不到；数据和用户关系保留。
- 永久删除技能。删除内置技能后，系统升级不会重建它。

管理员改过的内置技能，升级时不再用内置版本覆盖改过的部分；改过基本信息的 GitHub 技能，同步时保留后台填写的名称和简介。

## 创作首页纵深画廊与灵感库

创作页空态是直线纵深图片画廊：11 张横版卡片沿 Z 轴前后排队，当前一张在最前、最大，其余依次后退缩小并左右对称。滚轮、两侧按钮和自动轮播都能切换，切换只动 `transform` 与 `opacity`。卡片带玻璃描边、圆角和投影，底部是「行动点 / 标题 / 描述」三段信息，只有最前那张露出。队列跟随输入框的创作类型：选图片只排图片灵感，选视频只排视频灵感，选文本用本项目原创条目。每次进场和每次换类型都重新随机抽一批，并记住最近出现过哪些，走完一轮自动换批。

工作区左侧「创作」下方新增灵感页 `/inspirations`，展示全部提示词，按来源、分类和创作类型筛选，支持搜索、收藏、视图切换和分页；自建灵感支持新建、编辑、删除和 JSON 导入导出，改动只存在本地。

外部提示词由 `web/scripts/import-inspirations.mjs` 同步：`awesome-seedance`、好好学 AI 提示词库、YouMind 的两个姊妹库。脚本同时为画廊池生成本地缩略图（560px、webp、约 35KB 一张）。上游封面平均 400KB～700KB，直接引用一屏 11 张要拉 5MB 以上，换成本地缩略图后约 400KB。

画廊池走 `public/inspirations/gallery-pool.json` 运行时拉取，不打进首屏 JS：几百条提示词正文压在包里是白背的，而这份数据只服务画廊一处。池子按来源等距抽取以横跨各分类，并且只收描述非空的条目，保证卡片三行版式不缺角；这些条目仍留在全量目录里供灵感页展示。

## 创作首页、最近画布与灵感大厅

根路径 `/` 与 `/create` 共用创作首页。空态首屏提供紧凑标题、文本/图片/视频/Agent 模式、真实提示词输入区和快捷创作入口。下方一行展示创建画布与最近更新的 4 个画布，支持打开、查看全部和窄屏横向浏览；读取失败提供重试，创建后明确区分本机保存与云端同步。

灵感大厅合并到创作首页下方，不再提供独立灵感导航或 `/inspirations` 页面路由。类型与搜索常驻，来源、分类、收藏/隐藏和排序收拢在更多筛选中；默认每页 30 条。新建、编辑、隐藏/恢复、收藏与 JSON 导入导出继续保留，本地改动按账号 scope 持久化。使用灵感会关闭详情、回填首页提示词并返回输入区，不自动生成。

默认排序为“每日推荐”：内置条目按本地日期加条目 ID 的散列排序，同一天内顺序固定，翻页和刷新结果一致；过了本地零点换一批，标签页隔夜后回到前台时自动切换并回到第一页。自建条目始终排在最前。排序还可改为“最新上架”或“按标题”。

灵感上新：后端每 6 小时从 YouMind 提示词库和 awesome-seedance 同步正文为中文的新条目，补在内置目录之后，按 ID 去重，内置目录已有的以内置为准。首次收录 7 天内的条目带“新”标记，每日推荐把其中最新的最多 12 条排在最前，计数旁显示本周上新数量。英文条目仍需人工翻译后随版本发布。管理员在「功能开放 · 页面辅助 · 灵感上新」开关并立即同步，查看上次同步结果与错误；关闭后前台只展示内置目录。

内置提示词统一提供中文正文，详情阅读、复制、编辑和回填创作使用同一份中文内容。已有中文来源直接采用中文版本，其余外文正文翻译后随静态目录发布；模型名、引用标记和模板参数保留原有用途。来源及原页链接显示遵循后台来源展示开关。

译文维护在 `web/scripts/data/inspiration-prompts-zh.json`，记录原文 SHA-256；导入脚本写入目录前校验原文版本，缺译会停止导入。

外部提示词由 `web/scripts/import-inspirations.mjs` 同步。`web/public/inspirations/*.json` 继续提供静态目录数据，灵感大厅进入可视区域附近后才按需加载全量目录，浏览器缓存与会话内缓存避免重复请求；封面保持稳定比例，加载失败显示占位内容。

## 画布外观预设

电商创作入口 `/ecommerce` 按「准备素材 → 选视觉方向 → 确认方案 → 生成图片 → 导出交付」五步走完一轮，完成后可导出、拼长图、做成商品视频或继续下一组；后台“电商 Agent”包含知识库、Skills、行业与子品类，提供上线检查、两个阶段模型（商品识别与视觉方向、整套策划）、KB01–KB19、61 个内置方法包和完整中英文分类字典。知识数据升级时自动初始化，见 [电商 Agent 与知识库](../backend/ecommerce-agent)。

顶部保留浅色、深色和自定义三个入口。浅深切换恢复该色调最近的预设或微调；自定义仅展开、收起当前色调的设置，切换浅深不会改变展开状态。浅色提供经典浅灰、粉色、米色、浅绿，深色提供经典深色和柔和深灰；可调整明亮度、网格强度，并在“更多颜色”中修改背景和网格颜色。

单个画布自动保存预设快照、浅深色各自的微调和网格样式，工作台主题切换不覆盖已有画布。未设置新画布默认时，新建画布随工作台明暗选择经典预设，并默认使用线网格；旧画布缺省仍按点网格处理，已有显式颜色和参数继续读取。“设为新画布默认”仅作用于当前账号与本浏览器。外观及添加节点面板限制高度并允许内部滚动。
