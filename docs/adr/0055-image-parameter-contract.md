# 图片参数声明与生成合同

图片协议通过 provider contribution 的 `imageParameters` 声明字段名称、标签、类型、默认值、适用模型、计价资格和请求绑定。渠道可自定义已声明字段的支持值、数值范围和步长，不受插件初始范围限制；服务器读取插件定义固定字段类型、绑定和计价资格，再按模型配置校验输入。该配置不保证上游支持扩展值。

分辨率（imageResolution）、质量（quality）、比例或尺寸（size）是独立语义。管理表单、价格条件、前台模型、创作页、画布与 Agent 审批读取同一合同。pricing=false 的参数仍参与生成，价格表单仅显示 pricing=true 且启用的字段。枚举用平铺选项，数值、布尔和文本使用对应控件。

分辨率关闭时比例配置显示一组，开启时按管理员当前填写的档位显示。size.defaultTier 指定关闭分辨率后的有效像素组；存储保留其他组，重新开启时恢复。多个像素组缺少明确默认组时拒绝保存与执行。纯比例协议不需要像素换算。像素协议只使用已声明预设，不根据模型名猜测输出尺寸。

新配置或新增组默认选择 1:1、4:3、3:4、16:9、9:16、21:9，管理员可添加其他比例；已保存的选择和精确像素保持。capabilityOptions 保存公开意图，config.size 保存实际请求编码，扩展字段不能覆盖已经转换的像素值。

宿主在请求内部携带模型参数合同，先按模型范围验证，再替代插件对同一已提交参数的重复范围校验；模型、提示词、媒体和混合字段规则继续执行。自由输入的空枚举数组须在 JSON 保存后保留。Gemini 自定义分辨率只从已校验的图片参数透传，旧请求中的视频清晰度值仍省略。

本次使用已有 JSON 列，没有数据库迁移。未声明 imageParameters 的插件保持既有处理路径。升级插件时需同时更新源码 manifest、嵌入说明和安装包。

自由像素尺寸初始化常用比例，实际编码尺寸同步传入插件参数；声明的比例标识（例如 21:9）在能力范围、准入和执行之间保持原值，不转换为等价的 7:3。切换模型能力或协议时整体替换能力配置，清除旧协议字段。

验收覆盖仅分辨率、独立分辨率与质量、MJ 非计价扩展、字段关闭与重开、保存重读、精确像素、false/0、非法绑定、越界参数和定价一致性。真实供应商生成与费用需由维护者在自己的渠道单独验证。
