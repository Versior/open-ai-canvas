# 视频复刻：局部翻拍（换商品）与接入剪辑方案

状态：部分实现。最后一步定为进画布：「去画布复刻」按分镜重拍或沿用原片画面，有商品的镜头用实拍商品图生成换商品首帧，在画布的分镜脚本里逐镜出视频、合并成片（见 [待测试](../content/docs/progress/pending-test.mdx)）；复刻页一条龙、服务端拼片后进剪辑工作台尚未实现。拆解分析里逐镜的商品角色、关键颜色和「动作写过程」已实现，见 [功能 · 视频复刻：拆解](../content/docs/overview/features.mdx)。

## 结论

- **剪辑直接用影策现有的，不搬参考项目的 Python 脚本。** 影策已有剪辑工作台（时间线、预览、检查器、素材、字幕、转写、导出、AI 编辑八个插槽）、画布时间线和服务端渲染 `POST /api/timeline/renders`。翻拍出的镜头排进时间线，由服务端渲染出成片，再在剪辑工作台精修。
- **「不全部复刻、只换商品」可以做。** 按镜头决定保留还是重做：有商品的镜头用真实商品图改首帧，再图生视频；其余镜头按原片描述重新生成，或者（自己的视频）直接用原片。最后按原片节奏拼回去。
- 参考项目 [daihuo-fanpai](https://github.com/wangcanyu/daihuo-fanpai)（MIT）的拆解思路已吸收：逐镜记下商品怎么出现、商品角色、关键颜色，动作写过程并原样带进首帧和视频提示词。

## 参考项目的做法

daihuo-fanpai 是给编程 Agent 用的一条流水线：反推分镜 → 列资产清单 → 规划分段并写提示词 → 配音 → 生成 → 拼接 → 评分 → 字幕 → 交付剪映草稿或烧好字幕的成品。可借鉴的做法：

| 做法 | 说明 | 影策里怎么用 |
| --- | --- | --- |
| 逐镜标商品角色 | 没有商品 / 商品出镜 / 质感特写 / 包装文字，决定这一镜怎么重做 | 已加进拆解分析（`productRole`） |
| 动作原样进提示词 | 反推后写提示词时动作容易被概括掉，所以动作写过程、颜色写清楚 | 已加进拆解提示词 |
| 商品图由用户准备 | 模型画不出用户的真品，包装上的字也画不准，实拍图还自带尺寸感 | 翻拍时必须选或上传商品实拍图 |
| 人物用新身份 | 不照搬原片出镜人的长相 | 默认方式不用原片画面和人物 |
| 先审再生成视频 | 首帧便宜、视频贵，生成前先人工过一遍 | 先出首帧给用户确认，再出视频 |
| 多种模式 | 忠实复刻、产品迁移、跨类目改台词、模板直生、动作复刻等 | 第一期只做换商品，其余放第二期 |

## 影策现有能力

| 能力 | 位置 | 翻拍里的用途 |
| --- | --- | --- |
| 拆解：切点、关键帧、宫格、口播转写、逐镜分析 | 视频复刻页 | 起点 |
| 图片编辑（多张参考图） | 生成任务 `/api/tasks`；参考图上限按模型能力配置，默认 16 张，即梦 14 张，Seedream 10 张 | 关键帧 + 商品图 → 换好商品的首帧 |
| 首帧图生视频 | 生成任务；时长按模型能力配置，默认 1–15 秒；方舟（Seedance）还能带参考视频和参考音频 | 把换好的首帧做成这一镜 |
| 商品库 | 电商生图台的商品（外观真值图） | 直接选商品图 |
| 服务端渲染 | `POST /api/timeline/renders`：按时间线裁切、补空隙、拼接，音频轨片段按时间混入，字幕单独出 SRT（不烧录） | 拼成片 |
| 剪辑工作台 / 画布时间线 | 剪辑工作台插件、画布时间线弹窗 | 精修 |
| 缺口 | 剪映草稿导出；浏览器导出的音频轨还没做混音（`timeline-to-ffmpeg.ts`） | 拼片只走服务端渲染 |

## 局部翻拍

### 两种方式

1. **换商品重拍（默认）**：结构、动作、节奏、口播照原片；有商品的镜头换成用户的商品，其余镜头按原片描述重新生成（新的人物和场景）。适合参考别人的爆款做自己的。不使用原片画面、人物和声音。
2. **只重做有商品的镜头**：没有商品的镜头直接用原片画面，声音用原声。只适合用户自己的或已获授权的视频（例如换新品再发一条），开启前要勾选确认。

### 每个镜头按商品角色处理

| 商品角色 | 换商品重拍 | 只重做有商品的镜头 |
| --- | --- | --- |
| 没有商品 | 按描述重新生成 | 保留原片 |
| 商品出镜 | 关键帧 + 商品图改首帧 → 图生视频 | 同左 |
| 质感特写 | 同上，必须用实拍图，最好多给细节图 | 同左 |
| 包装文字 | 用包装实拍图做首帧，轻运镜；字不清楚时后期贴图 | 同左 |

每镜都能手动改成「保留 / 重做 / 删掉」。早期拆解没有商品角色时，由用户在列表里勾选哪些镜头有商品。

### 流程

1. **选方式、选商品**：从电商生图台选商品，或上传 1–4 张实拍图，加一句话描述（材质、颜色）。
2. **逐镜确认**：列出每镜的关键帧、商品角色、要做的事和预计费用。
3. **先出首帧**（图片编辑）：用户逐张确认，不满意的单张重新生成。
4. **再出视频**：按每镜的视频提示词和原镜头时长生成；原镜头比模型最短时长还短时，生成后在拼片时裁短。
5. **拼成片**：每镜摆回原位置，重做的镜头裁到原镜头时长；方式 2 用原声，方式 1 先静音（第二期接配音）；字幕用转写或台词出 SRT。服务端渲染出 MP4，存进素材。
6. **精修**：「在剪辑工作台打开」，时间线已经排好。

任务都在服务端执行，离开页面不中断；每镜的计划、任务和结果记在这条拆解下面，刷新后继续显示。

### 剪映草稿

参考项目用 pyJianYingDraft 生成剪映草稿（视频、配音、字幕、贴字参考、空背景音乐五条轨）。草稿格式靠逆向得到，会随剪映版本变化：参考项目实测剪映保存草稿时会加密，但还能读明文草稿，并说明剪映升级后可能失效。建议先用剪辑工作台和 SRT，确实需要进剪映时再加「导出剪映草稿」。

### 边界

- 方式 1 不使用原片画面、原片人物和原片声音，不复刻背景音乐。
- 方式 2 只对用户自己的或已授权的视频开放，要勾选确认。
- 商品图必须是实拍照片。

## 分期

| 期 | 内容 |
| --- | --- |
| 第一期 | 两种方式、逐镜计划、首帧换商品 + 图生视频、服务端拼片、在剪辑工作台打开。后端：翻拍记录（每镜计划、任务和结果）、拼片接口；前端：复刻页里的翻拍面板 |
| 第二期 | 改口播（按新商品重写台词 + 配音或声音克隆）、换人物和场景（人设图、场景板）、动作复刻（参考视频）、剪映草稿导出 |
