# 品类规则与详情页顺序

每个品类只写最容易出错、最影响质感的地方，以及详情页通常的屏序。屏序是起点，可按商品与卖点调整。

| 品类（family） | 出图要点 | 详情页常用顺序 |
| --- | --- | --- |
| apparel 服装 | 表现面料的垂坠、纹理和真实褶皱；版型、领口、袖型、下摆长度、纽扣拉链和缝线保持原样，不瘦身、不收腰 | 头图 → 核心卖点 → 上身效果 → 材质工艺 → 细节 → 多角度 → 场景 → 尺码参考 → 参数 → 购买理由 |
| bags-shoes 鞋包 | 包袋保持包体结构、包带长度、五金和缝线；鞋履保持鞋楦、鞋底纹路和左右一致；皮革、织物与金属分别呈现真实质感 | 头图 → 核心卖点 → 上身效果 → 细节 → 材质 → 多角度 → 场景 → 尺寸 → 包装 → 购买理由 |
| jewelry 珠宝配饰 | 用受控的渐变反射表现金属和宝石；宝石数量、切面、镶嵌和链节不变，不加彩虹光或额外宝石 | 头图 → 核心卖点 → 佩戴效果 → 细节 → 材质 → 多角度 → 包装 → 尺寸 → 场景 → 购买理由 |
| beauty 美妆个护 | 保留瓶身、泵头、盖子和标签位置；玻璃保留通透和折射，膏体与液体颜色质地真实，不暗示医学功效 | 头图 → 核心卖点 → 质地成分 → 场景 → 细节 → 规格 → 多角度 → 包装 → 尺寸 → 购买理由 |
| food 食品饮料 | 突出新鲜感和可信的份量；包装与标签文字原样保留，食材点缀克制，不虚构配料 | 头图 → 核心卖点 → 场景 → 细节 → 原料工艺 → 规格 → 包装 → 多角度 → 尺寸 → 购买理由 |

## 平台要点

- 淘宝 / 天猫、京东、拼多多：首张主图多要求白底或浅底、商品主体清晰，主图文字面积要克制；详情页长图需按平台单张高度上限切片。
- 抖音、小红书：首图要在信息流里一眼抓住注意，更重场景与真实感；种草类内容避免硬广排版。
- Amazon 等海外平台：主图纯白背景、主体占比高、不放文字和水印；文案用目标市场语言，单位按当地习惯。
- 平台规则会更新：上架前以平台当前规范为准，本表只作出图起点。
